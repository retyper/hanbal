# 단련터 화면 (목록 + 장수 한 사람 쪽)

형 11-11: 「단련터는 너무 막 슬라이드 폭격으로 길게 만들어 놨다.」 장수 한 명 한 명이 중요하게 느껴지는 수집 게임의 명부 모양으로 다시 짠다.
셈(공 · 유물 · 능력치 올림)은 그대로다 (`src/realm/drill.ts`, `src/realm/relics.ts`). 화면만 바뀐다 (`src/ui/realm/drill.ts`).

## 조사 메모와 한계

웹 검색으로 성세천하의 실제 화면 설명은 못 찾았다 (공략 표·티어표뿐, 화면 구성을 적은 글이 없다). 붕괴: 스타레일 쪽도 위키가 「희귀도·길·속성」으로 거르고 찾는다는 것까지만 확인했고, 명일방주 화면은 이번 검색에 안 나왔다.
아래 가져온 것은 확인된 사실(희귀도·속성·길로 거르기, 이름 찾기, 미보유는 회색)과, 이 장르 화면을 아는 대로 적은 것(★ 표)을 섞은 것이다. ★ 는 다음에 직접 화면을 보며 맞춰 볼 것.

## 가져오는 것 다섯

1. **한 줄 = 한 사람, 가로로 넓은 그림 띠.** 얼굴이 오른쪽, 이름이 왼쪽, 왼쪽은 어둡게 눌러 글이 읽힌다. 한 화면에 7장 (`P.realm.drillRows`). 카드 키는 목록 칸 ÷ 7이라 폰이 달라도 7장이 보인다. ★
2. **한눈에 보이는 것은 몇 개만.** 이름 · 단련 단계 · 공(막대) · 낀 유물 · 나라와 기운. 능력치 여섯은 카드에 안 올린다.
3. **희귀도는 테로.** 왼쪽 띠가 등급 빛깔 (보통 회색 … 전설 붉은색), 큰 화면에서만 등급 알약. 각성한 장수는 불꽃, 쓸 공이 있으면 금빛 ▲.
4. **한 사람씩 들어간다.** 카드를 누르면 그 사람 쪽 (넓은 그림 띠 + 공 + 능력 / 유물 두 갈래). 한 화면에 다 들어가서 밀지 않는다. 고르기판(유물, 거르기, 도움말, 도감, 의리)은 아래에서 떴다 사라지는 판.
5. **거르기와 찾기는 한곳에.** 위에 찾기 칸 + 「거르기」 + 자주 쓰는 셋(공 남음 · 각성 · 유물 낀)만 놓고, 나라 · 기운 · 등급은 거르기 판에. 필터 줄은 밀리지 않는다. 고른 칸은 눌린 채(금빛 + ✓) 남는다.

## 모양

- 목록: 위 띠(제목 · 명수 · 유물 도감 · 도움말) / 찾기 + 거르기 / 빠른 거르기 / 카드 목록 / 아래 붙박이 단추.
- 장수 쪽: 그림 띠(이름 · 나라 · 기운 · 등급 · 단련) / 공 막대 / 탭(능력 · 유물) / 능력치 여섯 줄 (줄마다 처음 몸 줄무늬 · 단련한 몫 금빛 · 그릇 눈금 · +단추) / 아래 「목록으로」.
- 못 올리는 +는 죽이지 않고 누르면 까닭을 띄운다 (`aria-disabled` + `data-why`).
- 기운은 무기 갈래 대신이다 (장수 데이터에 무기 종류가 없다). 불 · 물 · 번개 · 바람 · 땅.

## 남긴 것 · 뺀 것

- 남김: 공 새기기 · 올리기 · 유물 끼우기 · 쓸 공이 남았을 때 한 번 붙잡기 · 카드가 숨 쉬는 금빛 · 의리 설명 · 유물 도감 · 끝 화면의 공 줄.
- 뺌: 카드 안의 레이더 · 설명 문단(도움말 판으로) · 카드마다 펼쳐지는 유물 고르기 · 둥근 청동 테 얼굴(그림 띠로).
- 새 글은 모두 `t()` (`dy.*` · ko/en). 수치는 `P.realm.drillRows · drillRowMinPx · drillArtPct`.
