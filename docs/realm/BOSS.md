# 거대 보스 전투 설계

2026-11-21 · 지시 55의 제작 전 설계. **아래 초·범위·배율·문턱은 우리 초기 제안이며 원작 실측값도, 검증 완료 수치도 아니다.** 코드·실행·자산 변경 없이 작성했다. 순서: 53-B 완결 → 55 이무기 완결 → 흑룡 → 구미호 → 불의 무녀 장군 → 불가사리 → 51.

## 판 흐름과 단계별 전환

53-B는 우선 현재 마지막 두목의 승리까지 완결해 배포한다. 55는 **새 거대 보스가 구현·검수된 스테이지만** 기존 마지막 두목을 약 10분 중간 보스로 전환한다. 미구현 스테이지는 기존 마지막 두목 승리를 유지한다. 최종 보스 없는 판, 중간 보스 처치 뒤 영구 대기는 금지한다. 전환된 중간 보스는 53-B의 수·50/30% 막·틈·상자를 보존하고 상자 선택 뒤 CONTINUE한다. 거대 보스 처치만 49 승리 막 내림으로 간다.

첫 시간 예산 제안: 중간 보스 600초 안팎(현재 판 길이 비율로 params), 새 최종 등장 1140초(19분), 등장 후 180초 분노, 최종전 상한 240초 → 최장 판 1380초(23분). 기존 시간 제한과 충돌하는지 먼저 측정한다. 240초는 구현 전 합의용 가설이며 기존 제한을 조용히 늘리지 않는다. 상한 도달은 시간 초과 패배와 남은 보스 HP%를 기록한다. 분노는 자동 즉사가 아니며 회복 간격·빈도를 조정해도 이미 약속한 예고와 안전로를 보존한다. 50-1 몰아침/숨 고름, 등장 전 생존율·판 전체 길이를 같은 기준으로 전후 비교한다.

## 공통 전투 계약

막 1=100~70%, 막 2=70~35%, 막 3=35~0%. 현재 수를 마친 회복 구간에서 문턱을 한 번만 처리하고 포효 뒤 다음 막으로 간다. 문턱 통과로 기존 예고를 지우거나 즉시 타격하지 않는다. 표의 막은 최초 해금이며 이후에도 사용한다. 막 2부터 이미 본 수의 연결, 막 3부터 지연 후속타를 연다. 각 막의 광역 위협은 동시에 하나만 유지하고 표의 안전로를 닫지 않는다.

**몸 준비 → 빨간 지면 위험 확정 → 타격 → 머리 노출 회복.** 빨강은 실제 피해의 합집합과 일치한다. 탄은 현재 위치뿐 아니라 예정 이동 위험을 시간에 맞춰 표시한다. 예고 뒤 추적·회전·착지점 변경 금지. 표의 예고는 몸 준비 시작부터 타격까지 총초이며 몸 동작을 먼저, 뒤에 바닥을 보인다. 0.5초는 소범위 단타에만 시험한다. 후속타도 몸과 바닥으로 별도 재예고한다. 같은 수 연속 금지, 거리·전후측 위치·살아 있는 부위로 후보를 거른 뒤 기존 seeded RNG로 선택한다. 후보가 없으면 회복 자세로 대기하며 봉인 수를 되살리지 않는다.

같은 수의 다음 사용은 표 시간 또는 +0.3초 유지 변형(합계 최대2.5초)을 seeded RNG로 미리 고른다. 몸의 유지 자세와 바닥 지속으로 차이를 읽히며 타격 직전에 박자를 바꾸지 않는다.

표 기호: P=장수 충돌 지름, W/H=전장 너비/높이. 모든 안전 통로는 첫안 **3P 이상**이고 현재 이동속도로 예고 안에 도달 가능한지 실제 입력으로 확인한다. 불가능하면 예고·범위부터 조정한다. 회복 초는 마지막 타격 뒤 머리 약점 노출 시간이다. 표에 없는 몸 접촉 피해는 주지 않는다.

## 부위와 이무기 첫 세로 조각

축과 소켓은 원본 픽셀 좌표·정규화 좌표를 함께 메타데이터로 보관하고 겹침 여백으로 벌어짐을 막는다. 흑룡은 양 날개·앞발·턱·꼬리, 구미호는 아홉 꼬리·팔, 무녀는 양팔·옷자락, 불가사리는 턱·발·철갑으로 같은 부위 계약을 확장한다. 인간형은 큰 2×2 동작 띠와 분리 꼬리/옷자락 중 자연스러운 조합을 고른다.

초기 피해 배율: 몸 1.0, 머리 1.5(회복 2.0), 날개 .7, 철갑 .5·파괴 노출 1.2. 각 부위는 독립 HP를 갖되 가산 HP로 전투를 늘리지 않는다. 한 화살은 한 틱에 한 부위만 선택하고 본체 피해와 부위 피해를 각각 한 번 처리한다. 파괴는 본체 사망과 구분한다. 턱·목·꼬리 파괴 시 그 수의 예약·유지 판정을 취소하고 앞으로도 제외한다. 이미 분리된 탄은 유지하되 추가 생성은 0, 미리 표시된 안전로는 보존한다. 머리 HP 고갈은 약점 파손 표시이며 죽기 전까지 본체 피해를 받는다.

## 판·화면·카메라의 책임

판 상태기계: 등장 → 후보 선택 → 몸 예고 → 지면 확정 → 실행 → 회복 → 다음 수/막 전환 → 사망. 부위 파괴·분노·시간 초과의 우선순위를 고정한다. 고정 tick의 순수 pose 계산을 판정과 view가 공유해 머리·입·발끝과 hitbox가 같다. 접지 목표·사슬 입력도 판이 소유한다. view는 읽기만 하며 보간·불티·화면 흔들림은 판정에 영향을 주지 않는다. replay는 seed·입력·params판·tick을 저장하고 다른 렌더 FPS에서도 공격 ID·좌표·부위 파괴 tick·결과 hash가 같아야 한다.

등장 시 카메라가 멀어져 온몸·발사점·안전로가 들어온다. 53-A 장수 확대와 별도인 **보스전 자동 framing 범위**만 허용한다. 확대 단추·칩·설정은 추가하지 않는다. 중하단 긴 가는 HP막대+이름, 노란 지연 잔상, 70/35 눈금; 작은 부위 HP는 해당 부위 근처. 중간 보스·정예는 위쪽 막대 유지. 조작부·이름·약점·안전로를 가리지 않는다. 설명 자막 금지. 손맛·시간·배율은 params, hidden이면 판과 연출 시계 모두 정지한다.

## 검수와 밸런스 완료 조건

53-B 실제 UI 측정 동안 root 소스를 동결한다. 55 구현 전 ordinary input의 장수·seed·기술 선택·SHOP·DPS·생존/판 길이를 고정 보존한다. 먼저 빨간 재현을 보고 구현 후 같은 입력을 통과시키며, 검사를 일부러 깨뜨려 부위 판정·봉인·안전로를 재는지 확인한다. 새 보스용 `tools/raid-ult-dps.ts` × `tools/raid-stage-balance.ts` 표에는 SHOP 0~.8, 분산/집중 나무, 승률 분자/분모·보스전 시간·남은 장수/보스 HP·실패 이유를 기록한다. **목표**는 SHOP0+분산 대부분 패배, 중간 SHOP+집중 약 절반 승리/90~150초, 높은 SHOP 거의 승리/약60초/HP여유다. 아직 측정 결과가 아니다. 회피 못 하는 공격으로 구매를 강요하지 않는다.

이무기 완료는 실제 여울 진입→약10분 중간 보스→상자 선택→계속 진행→19분 거대 보스→승리 또는 패배 결과까지 ordinary input으로 확인한 때다. 상태 주입·테스트 전용 승리는 증거가 아니다. 여섯 수·세 막·파괴 봉인·1~2초 머리 틈·전장 안전로·분노·시간 초과·남은 HP%·hidden pause·재현 replay를 확인한다. 폰 360/375/390/412, 가로844×390에서 온몸·HP·조작부·결과창을 확인하고 세로가 회전 안내 상태라면 그 사실과 실제 플레이 미검증을 구분한다. typecheck·test·빌드·실제 번들 로컬200 후 단계 커밋/푸시/CI·운영 확인을 남긴다. 현 문서는 그 검사를 실행했다는 기록이 아니다.
