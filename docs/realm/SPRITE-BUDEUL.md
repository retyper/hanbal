- 장수 `golbeol-2` → `gen-budeul.png`, 원초상 `public/realm/bust-hd/w-32-golbeol-budeul.jpg`.
- 짧은 머리, 볼의 흙자국, 갈대 도롱이와 부들 이삭, 검은 상의, 조개 달린 허리 줄, 오른손 단검을 유지한다. 투구나 갑옷을 추가하지 않는다.
- 부들 전용 하체 생성과 교정은 같은 앞발을 반복해 보류했다. 검수된 갯내의 짙은 바지·갈색 장화 네 보행 자세를 공통 하의 부품으로 재사용했다. 색·좌우 반전·다리 워프 없이 사용하고 부들의 고유 상체·도롱이·단검·허리 조개 장식을 덮어 보존한다. 이는 부들 전용 보행 네 컷을 새로 생성한 결과가 아니다.

## 규격과 타이밍

`public/realm/anim2/gen-budeul.png`: 5600×160 RGBA, 280×160 셀 20개. 서 있는 키 150px, 지면 y155. 공격 때 뒷발 기준 x110을 유지하며 칼끝까지 잘리지 않도록 가로 투명 여백을 둔다. 인물을 가로로 늘리지 않는다.

| 셀 | 자세 |
|---|---|
| 0–3 | 원본 대기 유지 |
| 4–11 | 공통 하의 네 실자세 TL→BR→BL→TR, 각 두 칸 |
| 12–17 | 준비·준비·찌르기·찌르기·회수·대기 |
| 18 | 피격 |
| 19 | 눈을 감고 완전히 옆으로 쓰러짐 |

준비·찌르기·피격은 Gemini의 부들 원초상/정지 참조 시트에서 분리했다. 최초 시트의 웃으며 손으로 버티는 쓰러짐은 보류하고 별도 생성 컷으로 교체했다. 쓰러진 그림은 전체 높이를 서 있는 그림에 맞춰 확대하지 않고 머리 크기로 정규화했다.

타격 재생기는 준비 12번 → 접촉 14번 → 복귀 17번을 사용한다. 접촉 칼끝 `(266, 51)`을 `battle-strikes.ts`에 연결한다. 찌르기 이펙트를 사용하며 같은 오른손이 단검을 유지한다.

원본·실패 후보·합성 스크립트·독립 검수 결과는 제작 채팅의 outputs/work에 보존한다. 단순히 네 패널이 생겼다는 이유로 보행을 통과시키지 않으며, 이미 실패한 동일 생성 요청은 반복하지 않는다.
