## 설계와 경계

- 일반 스테이지의 자연 스폰에만 40초 몰아침+18초 숨 고름을 곱한다. 숨 고름은 기존 곡선의 약 18%를 출발점으로 삼고 params에서 관리한다. 정예·두목의 시각, 판 길이, 플레이어 성장·상점·공격 수치는 유지한다.
- 첫 세 토막(두목 전 시간의 60%)은 근접 조합으로 배치한다. 후반은 근접 주력+적은 원거리로, 기존 궁수 그림을 화살비 발사자로 쓴다. 새 적 그림은 발주하지 않는다.
- 일반 스테이지의 화살비는 살아서 화면 안에 있는 궁수 한 명을 발사자로 삼는다. 머리 위 붉은 화살 표식을 달아 적대 공격의 주체를 보여 준다. 발사자가 없거나 죽거나 화면 밖이면 해당 발사자의 예약 화살비도 취소한다. 발사자 없는 동안 타이머를 따라잡아 연속 발사하지 않는다.
- 실제 카메라는 1/1.35/1.8배다. `camera.fieldView()`의 시야에서 고른 궁수 ID를 선택 입력 `barrageSource`로 넘겨 판 기록에도 압축해 보존한다. 확대/축소로 실제 보이는 발사자가 바뀌면 활성 화살비도 바뀐다. sim이 DOM이나 카메라를 직접 읽지 않는다. 같은 씨앗+같은 source ID를 포함한 입력은 같은 상태를 재생한다.
- source 입력이 없던 옛 기록은 파싱·재생 입력 형식을 지원하며 전체 판 시야를 기본값으로 쓴다. 50-1 이전 stage는 규칙·난수 소비 순서가 바뀌어 예전 종결 상태와 완전 동일 재현을 보장하지 않는다. 과거 엔진을 별도 보존한 재생기는 만들지 않았다.
- 창돌격꾼의 줄만 끈다. 범·투창 사냥꾼의 줄은 별개 공격이므로 유지한다. 움찔·번쩍은 기존 49의 흰 피격 처리·몸 찌그러짐을 읽기 전용으로 재사용한다. 예고 상태를 판에 추가하지 않는다.
- trial/vanguard 고유 페이싱·화살비 규칙은 유지한다. 기존 스테이지 tiers를 trial이 공유하지 않으므로 trial 표는 그대로 둔다.
- 일시정지·레벨업 선택 중은 기존처럼 판 시계가 멈춘다. 숨 고름도 그 시계에 따른다. 승리·패배 상태는 더 진행하지 않는다. 새 단추·칩·설명 글·판 사이 상점은 추가하지 않는다.
