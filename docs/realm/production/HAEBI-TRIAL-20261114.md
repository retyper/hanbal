# 해비 본편 각성 시련 + 수동 제작 꾸러미

2026-11-14. 이전 독립 10분 열전 위에 본편 연결. 커밋·푸시·배포·외부 생성 제출 없음.

## 구현

- 본편 장수 → 해비 상세 → 각성 시련에 도전 → 두목 격파 → 각성하고 본편으로 귀환 → 기존 각성 연출/장수 상세.
- 현재 해비의 실제 ID는 `tut-haebi` 하나다. `guya-3`은 쇠비이며 대상이 아니다.
- 해비는 첫 공훈 2회로 시련이 열린다. 이 단계에서 자동 각성하지 않는다. 이미 열린 시련은 패배 후에도 무료 재도전 가능. 타 장수의 기존 해금 경로는 유지.
- `trialReady`/`trialCleared`를 Hero에 저장. `completeTrial`은 원본을 변경하지 않고 보상 후보를 반환. 새 `onCheckpoint`가 같은 계절 저장을 완료한 뒤 UI가 채택한다. 저장 실패 시 승리 화면에서 귀환 재시도. 현재 iframe의 source/origin/token/캠페인 참조와 승리 시간대를 확인.
- 기존 각성 해비도 한 번 시련을 치를 수 있지만 능력치 보상은 중복 지급하지 않음. 완료한 시련에는 입장 버튼 없음.
- 모든 장수의 각성은 패배해도 그 캠페인 동안 유지. 불꽃은 기술 연료만 감소하며 0이어도 각성 외형·능력치 유지. 승리로 연료 회복. 과거 저장의 이미 사라진 각성을 추측해서 복원하지는 않음.
- 폰 가로: 확대 캐릭터, 전장, 조작 버튼을 화면 높이에 맞춤. 세로로 전환하면 전투 정지 + 회전 안내. 가로 복귀 뒤 직접 재개. 전체화면 버튼 제공. 브라우저의 물리적 회전 잠금을 강제로 바꾸지는 않음.

## 사용자가 직접 생성할 제작 페이지

- URL: `http://127.0.0.1:5174/tools/out/haebi-pack/index.html`
- 생성기 `tools/haebi-art-pack.mjs`. 이미지12/영상4, 참고 이미지와 순서, 다운로드 링크, 프롬프트/파일명 복사, 8/10초 전환, 진행 상태 저장, 필터. 기존 bake-pack에 링크 추가(기존 목록 재생성/삭제 안 함).
- 우선 7개: H01 숲 전장, H06 투사체 도끼, H09 충격파8컷, H10 각성 시작 원화, H12 귀환 시작 원화, V01 각성, V03 귀환.
- 확장 9개: 여울/목책 전장, 소품, 목책 파괴, 조합/전리품 아이콘, 선봉 원화·영상, 환경 영상.
- `manifest.json`과 `prompts/*.txt` 포함. 결과 파일명 `haebi-pack-v1-H01.png` / `haebi-pack-v1-V01.mp4`. JPG 원본은 같은 stem의 jpg로 허용. 사용자가 Downloads에 모을 예정. 아직 생성 완료/승인/설치된 에셋 없음.
- 브라우저 복사 결과(파일명/프롬프트), 10초 문안 전환, 필터 4/7개, 완료 상태 reload 유지 및 검수용 상태 원복 확인. 모든 파일 링크/의존성 존재 검사 통과. 화면 증거 `outputs/haebi-art-pack.png`.
- 기존 `bake-intake.sh`는 이 새 접두어를 처리하지 않는다. 다음 턴 사용자의 완료 요청 후 manifest와 Downloads를 대조하고, 품질 확인 후 필요한 파일만 처리. 전체 Downloads를 옛 자동 설치/커밋 스크립트로 넘기지 말 것.

## 다음 설계 — 아직 구현하지 않음

사용자는 각성 후에도 무쌍식 전투를 활용하길 원하며 ‘선봉에 서기’ 깃발을 입구로 제안했다. 논의 방향: 10분 각성 시련은 성장·조합을 쌓는 한 판, 반복 선봉 돌파전은 중요한 전투에서 선택하는 2~3분 전투. 각성 외형/고유 조합을 처음부터 활용하고 적 진형 약화·진입로 확보 같은 본편 결과로 이어진다. 결투는 적장 한 명 상대, 돌파전은 다수 상대. 매 전투에 강제 삽입하거나 즉시 전투 자동 승리로 대체하지 않는 방향. 빈도·위험/보상·플레이 진입은 추가 설계 필요.
