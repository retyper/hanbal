# 해비 열전 · 폭풍을 가르는 도끼

2026-11-14. 사용자 요청: 해비 확대 캐릭터 창과 무기 조합으로 성장하는 독립된 한 판. 후반에는 확실히 강해져 무리를 쓸어버리는 방향.

## 구현

- `raid.html`을 해비 전용 독립 모드로 교체. 본편 산적 사건의 기존 체험 진입 버튼과 핸들러 제거. 캠페인 저장/병력/보상에 영향 없음. 기존 90초 시뮬레이션 `src/raid/sim.ts`는 보존하되 새 화면에서는 사용하지 않는다.
- 최대 10분. 초반/결합/진격/압도/마지막 두목 단계, 2분 간격 정예, 9분에 두목. 두목 처치 승리, 체력 소진 또는 10분 만료 패배. 일시정지/재개/같은 초기 시드 재도전/새 시드 재도전/출전 화면 복귀.
- 해비의 손에 든 도끼는 유지. 파쇄 도끼, 회전 관통 투사체인 질풍 도끼, 폭발하는 홍련 부적, 연쇄 번개의 네 공격 중 도끼 포함 3종 선택. 추가 공격 2자리와 보조 능력은 구분. 메아리/공격 속도/범위 성장. 기세 획득 후 세 선택지, 21레벨 상한, 재추첨 3회. 첫 선택은 세 공격 중 고르는 것이므로 재추첨을 소모하지 않는다.
- 조합: 파쇄4+질풍3 → 도끼 폭풍(회전 도끼), 부적3+벽력3 → 뇌화 연옥(번개마다 범위 폭발), 질풍3+메아리2 → 천 갈래 바람(도끼 명중 시 분열). 슬롯 때문에 불가능해진 조합도 안내한다.
- 첫 조합 완성 시 기존 각성 외형으로 전환. 확대 창은 기존 20컷의 대기/공격/피격을 사용하며 도트 비율을 늘이거나 줄이지 않는다. 별도 옷 파손/영상 재생 없음.
- WASD/방향키/클릭·드래그 이동, Shift 회피, Space 범위 비기. 터치 버튼. 전체 무음. 기존 장수/산적/배경 에셋 재사용. 투사체와 이펙트는 Canvas 코드로 렌더, 이미지 생성 호출 0회.

## 구조

- `src/raid/haebi.ts`: 순수 상태·전투·선택·승패. core/rng 사용. UI는 고정 120Hz 입력.
- `src/raid/haebi-view.ts`: 읽기 전용 전장/확대 캐릭터 렌더.
- `src/raid-main.ts`, `src/raid/style.css`: 출전/전장/강화/결과 및 모바일 배치.
- `src/tune/params.ts`의 HAEBI_RUN: 주요 성장·공격·스폰 수치.
- `src/raid/haebi-replay.ts`, `tools/haebi-balance.ts`: 실제 이동/선택 입력을 사용하는 결정론적 검수 봇.
- DEV 전용 `?review`: 첫 성장/초반/중반/후반/승리까지 실제 시뮬레이션을 재생해 화면 검수. 능력값이나 무적을 주입하지 않는다. 검수 UI는 프로덕션 빌드에서 제외. 숨겨진 탭에서는 일반 rAF 취소, 재생 작업도 중지.
