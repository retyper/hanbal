# 각성 해비 · 선봉에 서기 (2026-11-14)

본편 각성 해비(`tut-haebi`)가 선봉 비기를 직접 쓰면 최대 180초 난전에 출전하고, 확보한 돌파를 같은 합의 실제 병력 손실과 앞줄 힘에 반영한다. 자동전투는 기존 기본 비기를 사용한다. 다른 깃발을 고르면 난전에 들어가지 않는다.

- 각성 해비의 비기를 선봉으로 고정. 불꽃 0에서도 가능하며 유물의 굿 대체보다 우선한다. 튜토리얼에서도 각성한 뒤에는 겨루기/포획 전용 안내 제한을 해제한다.
- Lv9, 파쇄도끼4/질풍3/메아리2/기세1/범위1, 도끼폭풍+천갈래바람으로 시작. 15/65/115초부터 전위대장 순차 출현. 셋을 쓰러뜨리면 즉시 완료, 시간 초과/쓰러짐/자발적 귀환은 확보한 성과를 보존한다.
- 0/1/2/3돌파 = 적 앞줄 0/4/8/12% 손실, 이번 합 아군 앞줄 힘 1/1.35/1.55/1.75배. 난전 격파수 자체를 본편 사망자로 환산하지 않는다. 적 전체 병력에 피해를 주거나 자동 승리시키지 않는다.
- `RoundOrder.breakthrough` 영수증을 명령에 저장한다. 해당 장수·플레이어·비기·0~3 정수·미사용 여부를 검증하고 기존 장수별 전투당 비기 소모에 따른다. 다른 장수에게 전가하거나 다음 합에 중복 반영하지 않는다.
- 이미 치른 난전은 본대 명령 전에 반영한다. 이후 적의 겨루기/포획/퇴각 때문에 취소하지 않는다. 고정 비율에 병력 차이 보정을 다시 곱하지 않는다.
- iframe 메시지는 동일 출처/창/난수 토큰/출전 여부/시간 범위를 검사하고 한 번만 수락한다. 출전 전 취소는 합전으로 돌아간다. 출전 후에는 일시정지에서 성과 귀환. 본편 전투가 끝나면 기존 `host.done → advance → 저장` 경로를 사용한다. 각성을 해제하는 코드는 없다.
- 전용 배경·전위대장 그림은 아직 없으므로 기존 전장과 두목 에셋을 재사용한다. 사용자 생성 이미지/다운로드는 건드리지 않았다.
