# 현재 Veo 제작 기준

2026-11-07 사용자 검수 반영. 이 문서는 현재 품질 기준이며, 실제 제출 가능 여부는 현재 소유자·브라우저·라이브 제작 원장으로 확인한다. [현재 인수인계](../../../HANDOFF.md), [제작 스냅샷 안내](README.md).

## 대상과 참조

- 20~30대 여성 장수 **1차각성**을 우선한다. 남성·노년·2차각성은 후순위. Jay/u4는 Veo에 우선 배정하며 다른 계정의 전투 이미지 생성과 구분한다.
- 캐릭터별 한 편씩. 이미 완료/생성 중/대기 중인 요청을 확인하고, 현재 사용자가 교정하는 원본 25명은 제외한다. `w66 사로 노을`이며 `g66`이 아니다. 체크 표시나 파일 발견만으로 해제하지 않는다.
- 좋은 기준은 `w-77-sabeol-malgalgi`, 소서노(`l-L2-soseono`), `w-30-guya-soebi` 영상의 인물 크기와 자연스러운 움직임이다. 텍스트 설정보다 직접 확인한 현재 원본 그림의 얼굴·표정·복식·손·소품을 따른다.

## 구도와 움직임

- Gemini 입력 UI에서 **세로 9:16을 직접 선택하고 현재 선택 표시까지 확인**한다. 새 채팅 기본값 16:9를 그대로 쓰거나 문안에 9:16만 적고 제출하지 않는다.
- 머리부터 골반까지 화면을 크게 사용한다. 1:1 원본 네모를 세로 캔버스 가운데 작게 넣거나 흐린 띠를 붙이지 않는다. 원본이 전신이 아니어도 새 전신 그림을 만들 필요가 없다. 주요 손 파지는 보존하고 소품 끝/주변 배경의 자연스러운 일부 잘림을 과도하게 금지하지 않는다.
- 카메라·구도를 안정적으로 유지하며 인물별 목적 있는 대표 동작 하나를 준다. 매화보다 약간 읽히는 무게 이동·상체 기울기·어깨 움직임과 머리/천/장식의 후행을 연결한다. 회전·과장된 휘두름·소품 관통으로 역동성을 대신하지 않는다.
- 호흡은 흉곽·가슴·의상이 함께 움직이고 자세가 멈추면 부드러운 조직/옷감이 약간 늦게 잦아드는 변화로 읽혀야 한다. 몸통 전체만 통째로 이동하거나 얼굴/상체를 얼리지 않는다.
- 웃음은 모든 장수의 기본 행동이 아니다. 활짝 웃는 원본과 성격에 맞으면 눈가·볼·턱·어깨가 짧게 한 번 반응하고 편안한 대기로 돌아간다. 반복 웃음 금지. 소리는 보이는 호흡·표정과 어울려야 하며 거친 숨만 들리는 결과를 통과시키지 않는다.
- **단일 연속 촬영**: 중간 포즈/얼굴/조명 리셋, 숨은 편집, 멈춤 뒤 프레임 점프를 금지한다. 완벽한 시작/끝 루프보다 인물 일관성과 자연스러운 품질이 우선이다. 첫 포즈로 순간 이동해 강제 루프를 만들지 않는다.

## 검수와 소비 제한

- 새 대상 첫 편을 검수한 뒤 다른 인물로 진행한다. 원본/문안 SHA, 계정, 제출 시각, 대화 URL, 다운로드 파일과 판정을 라이브 원장에 연결한다. 기존 생성물을 덮어쓰지 않는다.
- 실제 픽셀 비율, 얼굴/복식, 같은 손의 파지/소품, 호흡·표정, 중간 연속성과 끝/시작을 확인한다. 전 프레임 인접 차이는 후보 검출이며 수치만으로 자동 채택하지 않는다. 크게 달라진 인접 프레임을 직접 비교한다.
- 실제 청취·입모양-소리 동기를 확인할 수 없으면 **미검증**으로 남긴다. 보조 AI의 설명을 직접 청취로 기록하지 않는다.
- 실패·한도 거절은 자동 재제출하지 않고 결과와 원인을 남긴다. 같은 인물 반복 재생성, 유료 업그레이드, 기존 요청 중복 금지. 실제 UI에 나타난 다음 사용 가능 시각으로 기존 예약을 갱신한다.

## 화면 적용 계약

- 각성 섬광 전의 일반 초상/기존 연출은 유지하고 섬광 뒤에 각성 영상과 해당 액자를 전환한다. 영상과 능력치가 서로 가리지 않아야 한다.
- 영상은 원래 비율과 가능한 영역을 크게 보여준다. 테두리와 워터마크 대응 문양이 인물을 가리지 않아야 한다. 사용자 문양 요구는 무기를 넣지 않은 육각형 보석·각성 동물 실루엣이다. 전략회의에서는 일반 대화 초상처럼 주변부를 가린다.
- 위 계약은 사용자 요구이며, 문서를 읽었다는 이유만으로 모든 화면의 최신 실기 검수가 끝났다고 간주하지 않는다.
