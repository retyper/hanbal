## 규칙 정본

뿌리는 각 무기 묶음의 주 무기·보조 공격·단단한 몸·몰아치는 기세입니다. 다른 일반 칸은 다음의 실제 부모 1단과 기존 갈래 합계 문턱 `[0,3,7,12]`를 모두 요구합니다. 일곱 묶음에서 주 무기와 보조 공격만 해당 묶음의 기술로 바뀝니다.

| 부모 | 자식 |
|---|---|
| 주 무기 | 큰 물결·홍련 부적 |
| 큰 물결 | 묶음별 벼리기 |
| 묶음별 벼리기 | 주 무기 갈래 끝 |
| 보조 공격 | 메아리·벽력 |
| 메아리 | 묶음별 숙련 |
| 묶음별 숙련 | 보조 공격 갈래 끝 |
| 단단한 몸 | 숨 고르기·굳센 몸 |
| 몰아치는 기세 | 날랜 발 |
| 굳센 몸 | 되받아치기 |

- 정본 API는 `haebi.ts`의 `powerParents(kit)`, `nodeParent(kit,power)`, `nodeOpen(run,power)`입니다. 후보 생성과 실제 선택이 같은 `nodeOpen`을 사용합니다.
- 조합의 부모 둘은 기존 `COMBOS.needs` 그대로입니다. 조합 하나가3단계에 이르면 비기가 자동 강화되는 규칙도 그대로입니다.
- 갈래 합계는 기존대로 시작 주 무기 1단을 포함합니다. UI에 표시한 ‘갈래3회’는 현재/필요 비율이나 Ψ 기호가 아닌 문턱의 짧은 이름입니다.
- 카드의 기존 열림 안내는 가상으로 다음 단계만 계산해, 그 카드를 고르면 실제로 열리는 칸만 표시합니다. 판 상태를 변경하지 않습니다.

- 일반16·조합3·자동 비기 강화1로 정보 노드20개입니다. 노드마다 그림은 하나씩, 전체 그림도20개이며 조합 부모 그림을 복제하지 않습니다. 노드 이름과 설명은 하단 정보 줄에만 나타납니다.

- 실제 선은 일반 부모12개, 조합 부모6개, 자동 강화 대안3개로21개입니다. 조합 경로는 기둥 사이의 통로와 서로 다른 아래 꺾은선으로 돌아가 실제 조합 그림으로 들어갑니다. 자동 강화의 세 선은 모두가 아닌 어느 하나3단계라는 `any` 관계입니다.
- 잠김은 어두운 그림과 자물쇠, 열림0단은 밝은 테두리, 찍은 칸은 갈래색과 그림 아래 실제 단계 숫자, 이번 카드 후보는 금빛 호흡 효과입니다. 금빛 후보는 `run.offers`에 있는 칸에만 붙습니다.
