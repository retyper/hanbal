## 실제 조건과 표시

- 일반 기술의 조건은 같은 갈래에 쓴 단계 합계 `[0, 3, 7, 12]`입니다. 특정 직전 기술을 선택하거나 최대 단계로 올릴 필요가 없습니다. 예를 들어 도끼 7단계, 큰 물결 0, 홍련 부적 0이어도 도끼날 벼리기는 후보 자격이 열립니다.
- 갈래 누적은 갈래 모양 그림과 `현재/필요` 숫자로 표시하고, 짧은 화살표가 해당 기술 그림을 향합니다. 조합에는 정본의 `needs`에 적힌 기술 그림과 단계만 표시합니다.
- 조합 3개 중 하나가 3단계이면 비기가 자동 강화됩니다. 이 칸에는 현재 선택 후보의 빛을 주지 않습니다.
- `.is-offered`는 `s.offers`에 실제 들어 있는 기술·조합에만 붙습니다. 소유, 최대 단계, 후보 풀 자격은 별도 상태로 표시합니다. 조건을 채웠지만 제시되지 않은 조합도 빛나지 않습니다.
- 선행 기술 그림은 같은 기술을 가리키는 참조입니다. 긴 교차선을 그리는 대신 해당 조합 옆에 그림을 다시 놓아 실제 조건에서 조합 그림으로 화살표를 연결했습니다.
