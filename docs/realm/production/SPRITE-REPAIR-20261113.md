## 검수와 한계

- 새 생성 요청 0건, 생성 크레딧 0. 절감률이나 전체 장수 품질 동등성은 측정하지 않았다.
- 두 장수 40컷 가장자리 최소 2px 이상, 원본 SHA256 불변, 설치된 PNG와 보정본 바이트 일치.
- Python 회귀 3개: 격자를 넘은 도끼를 보존하며 이웃 인물 배제, 청동/옅은 녹색 보존, 잘못된 배경 좌표 거부.
- 관련 TypeScript 시험 41개 통과(겨루기·번역·장수 그림·전투 타격), typecheck 통과. 실제 Chrome 1920px·390px 확인, 브라우저 오류 0. 실제 휴대폰 FPS·사용자 미감 판정은 별도.
- 기존 자동 감사 함수로 현 도트 장수 107개 검사: 범발 1개에 내부 직선 의심 경고. 이는 전수 미술 합격이 아니다. **한번 잘린 뒤 여백이 붙은 칼날/얼굴 내용은 경계 검사만으로 찾을 수 없다.**
- 얼굴 보정은 원본에서 직접 확인한 두 장수의 자세별 좌표에만 적용한다. 모든 장수에 같은 눈을 무작위 덧칠하지 않는다. 이 방식이 전문 도트 작가의 전체 수작업을 대체하거나 던파 수준을 보장한다는 의미가 아니다.

## 다시 굽기 / 다음 차례

저장소 루트에서:

```powershell
py -3 tools/sprite-kit/repair-pilot.py --out tools/sprite-kit/repairs/20261113
py -3 tools/sprite-kit/repair-pilot.test.py
node tools/sprite-normalize.mjs gen-haebi gen-aryeong
```

다른 장수는 원본·현재 띠를 먼저 비교한다. 원본에 남아 있는 무기는 전체 연결 추출로 복구하고, 눈은 해당 자세의 얼굴 좌표와 피부색을 검수해 부분 보정한다. 이웃 인물과 무기가 이어져 있거나 원본 캔버스 밖으로 사라진 경우 자동 추출을 강행하지 않는다. 필요한 얼굴/무기 부분만 편집하고, 포즈·해부학 자체가 망가진 컷만 마지막에 재생성한다. 현재 파일은 두 명 파일럿이며 신규 장수 등록 전 동작 순서도 별도로 정해야 한다.

원본 경계에 걸쳤다는 이유만으로 즉시 재생성하지 않는다. `widen-cells.py` 또는 이 복구 방식으로 살릴 수 있는지 먼저 확인한다. 큰 캔버스→작은 띠→확대→재축소 반복을 피하고, 무기 포함 여백·원본 비율·공통 팔레트·폰 1배 검수를 유지한다.

## 오픈소스 선택

- 이번 실행은 기존 설치된 Pillow·NumPy·SciPy만 사용. 새 게임 런타임 의존성·클라우드 호출 없음. [Pillow 공식 라이선스](https://github.com/python-pillow/Pillow/blob/main/LICENSE).

- [LibreSprite](https://github.com/LibreSprite/LibreSprite): 무료 오픈소스 도트 편집기, 프로그램 GPLv2. 현대 Aseprite는 소스 공개와 별도로 자체 EULA이므로 동일하게 취급하지 않는다.
- 던파의 선명한 얼굴·명암 덩어리·실루엣 같은 미술 원칙을 참고하되 기존 게임의 캐릭터 리소스를 가져온 것은 없다.

커밋·push·공개배포 없음. 비교 그림·게임 화면·전수 자동 경고 목록은 이번 Codex 채팅 outputs/sprite-repair에 제공.
