# 놀이 시험 — 페르소나 손님 (2026-10-27~)

형 (10-27): "우리가 바라는 대로 결과를 내는 시뮬레이션은 필요 없어. 진짜 유저들의 페르소나를 기반으로 그 행동을 모방해야 할 거야. … 게임 열자마자 나가는 사람들, 한 게임 해 보고 나가는 사람들, 아무거나 눌러 보는 사람들."

`tools/realm-sim.ts` 같은 봇은 **규칙**을 다 알고 끝까지 둔다 — 밸런스는 재지만 "헷갈려서 나간다"는 못 잰다. 그래서 셋을 따로 둔다.

| | 무엇 | 잡는 것 | 못 잡는 것 |
|---|---|---|---|
| ① 페르소나 손님 | 에이전트가 진짜 브라우저로, 정한 사람인 척 **스크린샷만 보고** 누른다. 마음 점수가 0이면 나간다 | 헷갈림 · 안내 빈틈 · 나가는 순간과 까닭 | 재미·재방문 예측 (사람이 아니다) |
| ② 막무가내 로봇 | 보이는 단추를 아무렇게나 수천 번 | 갇힘 · 오류 · 안 닫히는 창 | 사람의 마음 |
| ③ 진짜 사람 흐름 | 익명 흐름 기록 (첫 화면 → 시작 → 첫 계절 → 첫 싸움 → 떠난 자리) | 진짜 숫자 — ①이 맞았는지 | 왜 떠났나 |

## ① 손님 규칙 (프롬프트에 그대로)

- 저장 기록이 없는 포트(새 손님 자리)에서 시작 · 다른 포트·남의 탭 금지 · 제 탭은 끝나면 닫는다.
- **눈으로만**: screenshot · left_click · scroll · wait. javascript · read_page · find · page_text 금지.
- 누르기 전 속말("보인 것 → 하려는 것 → 왜"), 누른 뒤 "무엇이 바뀌었나 · 기분".
- 점수 3 에서 시작, 페르소나마다 깎이고 오르는 일이 다르다. 0 이면 그 자리에서 나간다. 누름 한도.
- 결과: 한 줄 요약 · 누름마다 시간표 · 헷갈린 곳 TOP 3 · 좋았던 순간.
- 한 번에 한 손님 — 브라우저 창이 하나라 스크린샷이 서로 가로챈다.
- 주의: 시험 도는 동안 저장소 파일을 고치면 vite 가 그 판을 새로 띄운다 (10-27 셋째 손님 중간에 한 번). 그리고 "새 손님 자리"는 예전에 쓴 적 없는 포트여야 한다 (5187 에 8일 전 판이 남아 있었다).

**셋이 겹친 것**
1. **눌러도 무엇이 됐는지 안 보인다** — 군사 20명을 뽑아도 병사가 안 나온다 · 선물·소문·회유가 무엇을 했는지 끝까지 모른다 · 출정을 잡은 뒤에도 금빛 「출정」 단추가 그대로.
2. **안내 밖을 누르면 아무 반응이 없다** — 막힌 건지 고장 난 건지 모른다 (두 손님).
3. **글자·숫자가 빽빽하다** — 첫 손님: "공부하러 온 거 아니야. 엑셀이냐."
4. **손을 끝까지 잡는다** — 고참: "첫 턴을 내가 정했다는 느낌이 없다" · 사로잡기 100% 가 마지막 도읍 싸움까지 이어져 진형 고름이 무의미 · "호위 207 인데 60 으로 잡을 가망 100%? 설명이랑 반대".
5. **좋았던 것은 셋 다 같다** — 지도가 처음 펼쳐질 때 · VS 화면 · 「대승」 연출 · 적장을 옥에 가두는 것 · 싸움 전 정보전(낌새·땅·매복).

→ 형의 지인과 같은 자리에서 같은 말을 했다 (첫 손님). 이 방법은 믿을 만하다고 본다. 다음 0장(문명처럼 작게 시작 · 할 일 한 줄 · 탭은 필요할 때)은 같은 셋을 다시 돌려 견준다.

## ② 막무가내 로봇 (10-27) — `tools/monkey.ts`

따로 띄운 헤드리스 크롬(새 프로필 = 저장 없는 새 손님 · 형의 크롬·저장은 안 건드린다)으로 5174 를 열고, 보이는 누를 거리를 아무렇게나 진짜 마우스로 누른다.
가끔 빈 곳도 누르고(6%) 밀어 내리고(8%) 꾹 누른다(5%). 구글 로그인·기록 내보내기는 안 누른다.

```
node --experimental-strip-types tools/monkey.ts [누름=1500] [씨앗=1] [폭=430] [높이=900]
```

잡는 것: 예외·console.error · **갇힘**(40번 눌러도 화면 그대로 / 누를 거리 0) · **맴돎**(200번 동안 처음 보는 누를 거리가 없다) · 떠남(다른 주소).
갇히면 `tools/out/monkey/s<씨앗>-<폭>x<높이>/stuck-<번>.png` 와 「살핌」(배우기 고리 자리·그 밑 요소·굴린 틀)을 남긴다.
주의: 배우는 판은 안내 밖 누르기를 먹지 않아서(고리가 튈 뿐) 「40번 그대로」가 자주 나온다 — 살핌의 고리 자리를 보고 진짜 갇힘만 고른다.

**1차 (폰 430×900 셋 · PC 1280×800 하나 · 1300~2000번씩)**
- 오류 **0** — 예외도 console.error 도 없었다.
- 고친 것: 배우는 판에서 지도를 밀거나 키워 누를 곳이 통째로 화면 밖에 나가면 고리가 안 보이고 어둠만 남았다(5/12 고리가 왼쪽 389px 밖) → 손을 떼고 `tutReturnMs` 뒤 다시 굴려 온다 ·
  영웅전처럼 긴 판을 한참 내리면 「‹ 돌아가기」가 저 위에 있었다 → 머리를 위에 붙였다(`.front .fhead` sticky).
- 고칠 거리 아님: 싸움에서 합 기록이 길어 폰에선 다음 합 판이 화면 밑 — 로봇이 밀기를 몰라 1000번 머물렀다(사람은 밀고, 판도 저절로 굴린다). 숫자 표 접기는 BATTLE-LIVE 0번에서.
