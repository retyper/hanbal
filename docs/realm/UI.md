# UI — 화면 여섯 장

> 원칙 셋: **마우스 하나**(W5) · **덮개는 한 장**(SYSTEMS §15-1) · **숫자는 문장 뒤에**(SYSTEMS §1-2).
> 화풍은 기존 행로도(`ui/mapart.ts`) — 어두운 화면 위의 낡은 종이, 먹선, 광곽. 판(저격)은 기존 신궁 화면 그대로.
> 아래 그림은 배치만 말한다. 크기·색은 R5 에서 브라우저로 보며 정한다 (CLAUDE.md "화면 확인").

---

## 1. 지도 — 이 게임의 집

```
┌───────────────────────────────────────────────────────────────────┐
│ 읍차 ○○ · 셋째 해 가을        곡식 1,240  철 38  가호 840  민심 62 │  ← 머리띠: 칭호 · 때 · 자원 넷
├───────────────────────────────────────────────────────────┬───────┤
│                                                           │ 보고  │
│        (종이 지도 — 고을은 먹점, 길은 먹선,                 │ ───── │
│         안개는 번진 먹, 우리 땅은 붉은 인주)               │ 세 줄 │
│                                                           │       │
│     ● 갈대 나루 ─ ─ ─ ○ ?                                  │ ───── │
│        ╲                                                  │ 장수  │
│         ● 국읍 ─── ● 철산                                  │ 얼굴  │
│                                                           │ 다섯  │
│                                                           │       │
├───────────────────────────────────────────────────────────┴───────┤
│  [도감]  [정책]  [소리]                                 [다음 계절 →] │  ← 버튼줄 — "다음 계절"은 늘 같은 자리
└───────────────────────────────────────────────────────────────────┘
```

- 고을 · 길을 **누르면** 오른쪽 띠가 그 판으로 바뀐다 (덮개가 아니다 — 지도는 늘 보인다).
- 장수 얼굴을 지도 위 고을로 **끌어다 놓으면** 그 고을의 일이 바뀐다 (팰월드 거점 배치). 누르기만 해도 일 목록이 열린다.
- 안개 속 고을은 `?`. 소문으로만 아는 고을은 **점선 동그라미**.
- 지도는 바뀔 때만 다시 그린다 (SYSTEMS §15-5).

## 2. 고을 판 (오른쪽 띠)

```
┌ 갈대 나루 ──────────────┐
│ "갈대가 사람 키를 넘는다." │  ← 꼬리표 문장 (누르면 풀이: 은폐 +0.15)
│ "물이 얕아 여울목이 보인다."│
│ ─────────────────────── │
│ 주인  북쪽 읍락 (긴장)     │
│ 병력  120~180  · 2계절 전  │  ← 정보는 범위와 나이로
│ 장수  ? (신중)            │
│ ─────────────────────── │
│ 기습  40~70%              │  ← 확률은 범위로 (정보의 계약)
│ [정찰]  [출정]            │
└─────────────────────────┘
```

- `사료` 표식이 붙은 문장은 **길게 누르면 원문 한 줄**이 뜬다 (WORLD §5 규칙 1).
- 출정을 누르면 군대·장수 고르기가 같은 띠 안에서 이어진다. 저격 명령(맡긴다/직접)은 군대의 줄에 있다.

## 3. 장수 카드

```
┌──────────────────────────────┐
│ [얼굴]  사미루  27  · 전설      │  ← 희귀도는 테두리 색(오방색) + 글자
│        미리미동국 강가 사람     │
│ 무 8  략 7  치 3  덕 4         │
│ 바람 없는 손 · 명궁 · ?         │  ← 숨은 칸은 "?" (있다는 것은 숨기지 않는다)
│ 충성 ███████░░ 72              │
│ ──────────────────────────── │
│ 셋째 해 겨울, 갈대 나루에서     │  ← 일대기 — 게임이 쓴 줄
│ 다리에 화살을 맞고 사로잡혔다.  │
│ ──────────────────────────── │
│ 일: 정찰 (갈대 나루)  [바꾸기]  │
└──────────────────────────────┘
```

## 4. 보고와 자랑의 한 줄

```
┌ 지난 계절 ──────────────────────────────┐
│ ★ 다리를 맞혔다 — 승률 31% → 58%.          │  ← 자랑할 순간만 크게 (SYSTEMS §13)
│   사미루를 사로잡았다.                     │
│ 겨울이 끝났다. 창고 −180.                  │
│ 포로 둘이 회유를 기다린다.                 │
│                                [더 보기] │
└─────────────────────────────────────────┘
```

- 최대 세 줄 + 자랑 한 줄. 덮개가 아니라 지도 오른쪽 띠의 맨 위다.
- "곧 끝나는 것"을 앞세우지 않는다 (SYSTEMS §15-3).

## 5. 사건 카드 (덮개 — 한 번에 한 장)

```
┌──────────────────────────────────────┐
│ [삽화: 하늘]                           │
│ 가뭄이 든다. 논바닥이 갈라졌다.         │
│                                      │
│ [소도에 빈다]        [보를 쌓는다]      │
│  곡식 −120           일손 −20%         │
│  점괘: 비 70% (소문)   다음 해 가뭄 −   │
│                                      │
│ 고르지 않으면: 보를 쌓는다             │  ← 기본값이 화면에 적혀 있다
└──────────────────────────────────────┘
```

## 6. 한 해 요약 (새해 — 멈출 자리)

```
┌ 셋째 해 ──────────────────────────────┐
│ 거둔 것   곡식 2,140 · 철 52            │
│ 잡은 이   사미루 (전설) · 무명 장수 둘    │
│ 잃은 이   없음                          │
│ 칭호      읍차 → 살해                   │
│                                        │
│ 걸린 일이 없다. 여기서 쉬어도 좋다.       │  ← 이 문장이 이 화면의 일이다
│                         [넷째 해 봄 →] │
└────────────────────────────────────────┘
```

- 이 화면에는 사건 카드가 없다 (SYSTEMS §15-3). 탭을 닫기 가장 좋은 자리다.
