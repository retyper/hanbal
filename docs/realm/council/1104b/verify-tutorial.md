# 바뀐 튜토리얼 확인 · 첫 싸움을 앞으로 (11-04)

14단계로 바뀐 튜토리얼(우리 땅 → 출정 → 전략 회의 → 전투 → 회유 → 옥중 담판 → 징병 → 개척 → 건설 → 정찰 → 사신 → 제사 → 공작 → 도읍 차지)을
새 손님처럼 첫 화면부터 승리까지 두 번 돌려 본 기록이다. 코드는 고치지 않았다.

## 어떻게 쟀나

- 5174 포트 · 헤드리스 크롬 · **새 프로필**(저장 없음) · 390×844 · 모바일 흉내. 형의 크롬은 안 썼다.
- 첫 화면 「앱으로 설치」 ✕ → 「처음이면, 배우는 판부터」 → 머리말 3장 → 그다음은 배우기 고리(`.tutring`)가 가리키는 곳만 눌렀다.
- 전장에서는 빛나는 것(튜토리얼 빛)을 따랐다. 「장수」 탭 → 「적장 사로잡기」를 **끌어** 놓기 → 나머지 무리는 ★ 권함을 끌기 → 「전투 개시」.
- 글자 수는 앞 기록(evidence.md)과 같은 방법: 화면에 실제로 보이는 한글, 같은 조각은 한 번만 셈.
- 스크립트: 스크래치 `council/verify/run.ts`. 스크린샷: 스크래치 `council/verify/shots/` (2회째) · `shots1/` (1회째).
- 1회째는 내 스크립트가 두 번째 전장의 무리 탭을 못 찾아 멈췄다(게임 탓 아님). 고쳐서 2회째는 승리까지 갔다. 아래 숫자는 2회째.

## 2. 오간 각성

**된다.** 첫 싸움(갯골벌, 1합 대승 · 해비 사로잡음) 뒤 「사로잡았다」 장면의 확인을 누르자 `.ascfx` 각성 연출이 떴다.
불꽃 칸 셋이 차고 「각성」 붓글씨, 능력치 무예 7→8 · 통솔 5→6 · 지략 6→7 · 내정 4→5 · 매력 5→6, 아래 「확인」. 두 번 다 같았다.
저장 판에서도 `tut-ogan` 은 `flames=3 · ascended=true`.
스크린샷: `shots/019-ascfx.png` (뜨는 순간) · `shots/020-ascfx-ok.png` (다 핀 화면).

## 3. 고리가 어긋난 곳 · 막힌 곳

**막혀서 못 간 곳은 없다.** 「막혔으면 건너뛰기」는 한 번도 안 떴다. 미추홀 정찰·사신, 4월 제사, 건설 모두 그대로 됐다.
작게 어긋난 곳:

| 단계 | 본 것 | 스크린샷 |
|---|---|---|
| 5/14 회유 | 싸움이 닫히자마자 고리가 「장수」 탭을 가리킨다. 누르면 그 위로 「사로잡았다」 장면 → 각성 → 소식판 → 「획득! 갯골 마을」이 차례로 덮는다. 이 넷이 뜨는 동안 고리가 없다(확인 단추를 가리키지 않음). 「획득!」은 3초쯤 띠 아래에 떠 있다가 걷힌다. 갇히지는 않는다. | `shots/016-step5of14.png` · `017-noring-dismiss.png` · `021-noring.png` |
| 3/14 전략 회의 | 이 싸움은 「장수들의 뜻이 갈리지 않습니다」라 아뢰는 장수가 없고 고리는 바로 「출정」. 띠 글은 「장수가 한 사람씩 아뢰면 눌러서 들으세요 … 따를 말을 하나 고릅니다」라서 화면과 다르다. (14/14 회의에서는 아뢰는 말 2개 + 고르기가 실제로 나온다) | `shots/007-step3of14.png` |
| 8/14 개척 | 고리가 「개척단」을 누르게 한 뒤 바로 다음 단계로 넘어간다. 솔뫼를 고르지 않았는데 아래에 「위례 도읍 개척단 · 보낼 곳을 선택한다」 띠가 남아 있다. 띠 글은 「빈땅 솔뫼로」라고 한다. (예전 기록에도 있던 것) | `shots/025-step9of14.png` (아래 띠) |
