## 오늘 저녁 둘째 PC 시험에서 물을 것

「PC 가 나아?」가 아니라:
- 몇 분째 처음 재밌었나 · 언제 지루했나 · 글을 읽었나
- 첫 깃발을 누르고 기다렸나, 끌었나 · ★ 아닌 깃발을 한 번이라도 골랐나 · "왜 이긴 것 같아?"
- 몇 번째 싸움에서 처음 맡겼고 그때 무슨 말을 했나
- 「새 전투 시험」 스위치는 끈 채로 (세 사람 모두 옛 화면으로 했다)

읽는 법: PC 에서는 손으로 하는데 폰에서 맡겼다면 → 입력 꼴(누르기/끌기) 문제. PC 에서도 맡기고 지루하면 → 고르기의 무게와 빈 달 문제(다섯 자리의 예측은 이쪽).
