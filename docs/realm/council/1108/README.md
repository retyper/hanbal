## 결정 (자리들이 쓴 뒤 채운다)

### 세 자리가 같이 짚은 뿌리

1. **값은 그대로인데 벌이는 수십 배.** 쉬움 이서 봇 판에서 가을걷이 33배·집 16배(s8→s99). 상단의 주문 한 가지는 곡식 60 어치 고정 → 초반 15계절치, 후반엔 창고 하나로 15~22번. 좋은 씨앗은 거꾸로(초반 손해 · 후반 15배 이득). (balance §2)
2. **쉬움에선 판 끝까지 아무도 우리를 노리지 않는다.** `easyFocus 0.5`(ai.ts:80-84)가 앞선 나라 노리기(0.12)·이기는 길 막기(0.2)를 이긴다 · 「앞서가는 나라」를 군세로만 가려(stance.ts:56) 살림으로 이기는 형은 걸리지 않는다. 값만 키워서는 안 된다 — 쉬움 살림 덤을 꺼도 우리/남 군사 7.8배 → 3.0배. (design · loop · balance 실험)
3. **결승선에 큰 장면이 없다.** 75% 알림(nearWinToast) 한 번. (loop)
