# 위원회 2차 · 「기록·과시 자리」 — 그래프와 사관의 붓

> 형 (11-03): *"문명처럼 턴마다 … 군사력이라던가 마을수라던가 단순집계 라인그래프"* · *"시대점수 … 매턴 뭘 하면 점수로 들어가고 게임종료시에 1~20 등급으로 말해줌. 우리는 뭔가 그런거 없을까."*
> 읽은 코드: `src/realm-main.ts`(`Turn` · `myLot` · `recordFor` · `saveGames` 3MB 상한) · `src/ui/realm/front.ts endingHtml`(끝 화면 필름이 이미 보고 줄에서 큰일을 뽑는다) · `src/realm/title.ts`(길마다 옛 임금 칭호 · "숫자 점수는 없다") · `src/realm/tier.ts`(촌장~천손) · `src/realm/calendar.ts yearOf·monthOf` · `ui/realm/logbook.ts`(지난 기록 판) · docs/realm/META §7-1 · DESIRE §3·§4.

## 0. 먼저 — 앞선 결정과 부딪히는 곳

META §7-1(10-24)과 `title.ts` 머리말은 **"등급은 따로 없다 · 숫자 점수 없음"**이고, DESIRE §3 ④ 열전도 "점수·등수·공유 보상은 없다"이다. 형의 이번 말은 이것을 **뒤집는다**. 그래서 아래 안은 그 결정의 까닭(엑셀 화면 · 남과 견주는 불안)만 지키고 점수를 들인다: **쌓이는 점수는 「붓 획」 그림으로, 판 끝은 숫자가 아니라 이름(스무 칸 칭호)으로, 남과 견주는 표는 없다.** 형이 이 선을 확인해야 한다(§5 Q1).

## 2. 그래프 — 「흥망 그래프」

### 무엇을 세나 — 줄 셋
- **군사**(머릿수) · **고을**(쥔 고을 수) · **백성**(집 수). 곡식·철은 가을마다 출렁여 줄이 톱니가 되니 뺀다(문명도 기본은 인구·군사·땅).
- 남과 견줌: **판 끝에는 모든 나라**(안개가 걷힌다 — 문명의 끝 리플레이처럼), **판 중에는 우리 + 아는 나라만**, 남의 줄은 **점선 띠**(정보의 계약: 남의 속은 범위 · 소문이 낡을수록 띠가 넓다).
- 색: 우리는 늘 **고정 파랑**(메모리 my-land-fixed-blue), 남은 나라 깃발 색. 눈금 숫자 없음(META §7-1) — 줄 끝에 지금 값 하나만.
- **큰일 표**: 아래 가로줄에 작은 그림 — 도읍 쥠(깃발) · 각성(불꽃) · 원수 갚음(붉은 낙관) · 큰 공사(성벽). 누르면 §3 사관의 한 줄이 뜬다. 그래프와 기록이 한 몸.

### 어디에 보이나 — 둘 다, 있는 화면에
- **판 중**: 나라 판 「이기는 길」 칸 아래 **작은 그래프 한 줄**(우리 + 가장 센 이웃). 그림 칩 셋(창 · 초가 · 사람)을 누르면 줄이 바뀐다. 새 화면 없음(DESIRE §4 ⓒ).
- **판 끝**: 열전 한 장(DESIRE ④)의 윗머리 — 모든 나라 줄. 「간직하기」 세로 그림에도 들어간다.
- 폰: 줄은 많아야 다섯(우리 + 큰 나라 넷, 나머지는 회색 한 줄로 묶음). 가로 360px 에서도 읽히게 굵게.

### 데이터를 어디서 — 셋을 견줌

| 길 | 결정론(A1) | 저장 | 판정 |
|---|---|---|---|
| **판 저장 `state.log` 다시 굴리기** | 이론상 같은 판이 나온다 | 0 | ✗ — 판의 **처음 모습이 없다**(`Saved` 는 지금 판과 한 계절 앞만 · 시작 때 단련·유물·동행을 판 밖 저장에서 붙인다 → 그 저장은 그 뒤 바뀜). 업데이트로 셈이 바뀌면 옛 기록이 다르게 굴러 그래프가 거짓말한다. 폰에서 60계절 다시 굴리기는 수 초 |
| **`Realm` 에 계절마다 한 줄** | sim 이 셈하니 깨끗 | `Saved` 가 판을 **두 벌**(realm·before) 들고 있어 두 배 · 결정론 시험값이 바뀜 | △ — 판 밖 표시를 위해 sim 을 건드릴 까닭이 없다 |
| **`realm-main.ts` 의 판 기록 `game.turns[].me`** | 화면 쪽이 판을 **읽기만** 함(규칙 2 그대로) · sim 무관 | 이미 계절마다 `{nodes, hh, men, grain, iron}` 을 적는다(우리 것만) · `saveGames` 3MB 상한·오래된 것부터 걷기 · 서버에도 맞춰 올라감(`sync.record`) | **◎ 이것** |

- 할 일: `myLot` 곁에 `lotOfAll(r)` — 모든 나라의 `[고을, 군사, 집]` 세 정수를 `Turn.them` 에 담는다. 스무 나라 × 세 수 ≈ 계절당 200자, 60계절이면 12KB — 이미 담는 보고 줄(`lines`)보다 훨씬 작다.
- 기록이 없던 계절(10-25 전 판 · 다른 기기에서 넘어온 판)은 그래프가 그 계절부터 시작한다. 빈 칸은 비워 둔다(지어내지 않는다).
- 달 시계 판(`clock: 'month'`)은 계절(석 달)마다 한 점으로 묶는다.
- 비용: **S~M · 그림 0장**.

## 3. 점수와 등급 — 「사관의 붓」

### 한 줄
판의 큰일이 계절마다 **『삼국사기』 본기 문체 한 줄**로 적히고, 한 줄마다 **붓 획**(1~3)이 쌓인다. 판 끝에 붓 획의 합이 **스무 칸 칭호** 가운데 하나로 말해진다.

### 「역사의 한 줄」 — 본기 문체
- 예: 「삼 년 봄 이월, 왕이 몸소 군사를 이끌고 아라를 쳐 크게 이겼다. 두만이 적장 솔뫼를 사로잡았다.」 · 「다섯 해 가을, 크게 가물었다. 왕이 곳간을 열어 백성을 먹였다.」 · 「여섯 해 겨울, 원수 거칠을 마침내 사로잡았다.」
- 해는 **즉위 n년**(`yearOf`+1) — 본기가 왕의 해로 세는 꼴 그대로다. 캠페인은 장의 서력 대신 「온조 n년」. 달 시계면 「이월」, 계절 시계면 「봄」.
- 한 계절에 **한 줄**(그 계절 가장 큰 일). 글은 쉬운 말·평서(이야기 글 규칙), 한자 없음, 조사는 `josa()`, 긴 줄표 없음.
- 뽑는 곳은 이미 있다: `endingHtml` 이 보고 줄(battle · take · relation · recruit · discover)에서 큰일을 고르는 셈 — 이것을 순수 함수 `annalsOf(r, history)` 로 꺼내 **끝 화면 필름 · 계절 보고 · 열전 · 그래프 표 · 점수**가 함께 쓴다. 판정 0, sim 무관.
- 보이는 곳: **계절 보고 맨 위 한 줄**(붓이 그어지는 짧은 움직임 + 획 수) · 「지난 기록」 판(logbook)에 **「사관」 칩** 하나(그 판의 본기만 모아 본다 = 문명 6 타임라인). 새 창 없음. 3획 일만 「획득!」 한 탭(DESIRE ⓑ).

### 붓 획 셈 (처음 크게 · 되풀이는 덜)

| 일 | 획 | 덧말 |
|---|---|---|
| 이긴 싸움 · 크게 이김 | 1 · 2 | 같은 나라에 세 번째부터 0 |
| 적장 사로잡음 | 2 | |
| 남의 도읍을 쥠 / 우리 도읍을 지켜 냄 | 3 / 2 | |
| 동맹 · 속국 삼음 · 혼인 | 1 · 2 · 2 | |
| **원수 갚음**(DESIRE ③) | 3 | 판에 원수 둘까지라 저절로 상한 |
| 장수가 처음 각성 | 2 | |
| 흉년에 굶은 고을 없이 넘김 · 곳간을 엶(진대법) | 2 | 「백성을 구함」 |
| 큰 제사 · 큰 공사 다 지음 | 1 · 3 | |
| 새 나라를 앎(셋까지) · 우리 장수가 됨 | 1 · 1 | |
| 이기는 길을 이룸 | 5 | 판 끝 |

- **빼는 점수는 없다.** 도읍을 잃은 계절도 적히지만 획은 0 — 손실 회피를 쥐어짜지 않는다(DESIRE §5-7). 질 판은 "덜 적힌" 판이다.
- 같은 일은 세 번째부터 0 → 긴 판에서 약한 나라 갈아 넣기로 등급을 올릴 수 없다(문명의 「최초」, 휴먼카인드의 빠름과 같은 까닭).
- 판 크기 맞춤: 문턱은 판(region)마다 다르다 — 작은 판 · 영남 · 큰 판. 난세 단계는 등급을 **한 칸씩 올린다**(촌장 −1 · 군장 0 · … · 천손 +4). 문명 4의 정규화와 같은 일.
- 문턱은 감으로 정하지 않는다: 봇 판(`tools/realm-sim.ts`)이 같은 `annalsOf` 로 획을 세게 하고, **신중 봇의 이긴 판 중앙값 = 열째**, 진 판 = 다섯째 안팎, 천손 빠른 이김만 열아홉·스물에 닿게 맞춘다(`npm run balance` 출력으로 BALANCE.md 에).

### 스무 칸 칭호 — 우리 칭호 사다리로
문명 4가 실존 지도자와 견준 자리에, 우리는 **사료의 칭호**를 스무 칸에 놓는다. 다섯 묶음 × 넷 — 마을에서 하늘까지.

| 칸 | 묶음 | 칭호 (사료) |
|---|---|---|
| 1~4 | 마을 | 나그네 · 촌장 · 읍차 · 살해 |
| 5~8 | 삼한 | 번예 · 험측 · **신지** · 진왕 |
| 9~12 | 북녘의 가 | 대가 · 고추가 · 국상 · 거서간 |
| 13~16 | 임금 | 이사금 · **마립간** · 왕 · 대왕 |
| 17~20 | 하늘 | 성왕 · **태왕** · 동명 · **천손** |

- 근거: 읍차~신지(위서 변진조 · WORLD §6-1) · 진왕(한조) · 대가·고추가(위서 고구려조) · 국상(고국천왕 때 을파소) · 거서간·이사금·마립간(신라본기 · 『삼국유사』) · 태왕(광개토왕릉비 · `tier.ts` 단계 이름과 같은 낱말) · 동명(주몽 시호) · 천손(`tier.ts` 끝 단계). 「성왕」은 백제 성왕과 겹치니 「성군」도 후보.
- 판 끝 말은 **「[이긴 길] + 칭호」** 한 마디로 `title.ts` 와 합친다: 「칼로 판을 쥔 **마립간**」 · 「여러 군장이 받든 **신지**」 · 「쇠의 바다를 쥔 **대왕**」. 진 판은 「꿈을 접은 **험측**」. 지금의 옛 임금 칭호(동명·혁거세·수로·해모수·비류)는 그 아래 한 줄 「○○처럼」으로 남는다.
- 화면: 스무 칸 **붓 막대**(먹이 칸을 채워 간다)가 차오르다 그 칸에서 낙관이 「쾅」 — 네모 붉은 도장(둥근 것 금지 · 일장기 결 금지). 숫자 점수는 보이지 않는다. 칸 번호도 안 쓰고 칭호만.
- **휘장 탭(META §7-2)**: 78국 칸마다 **그 나라로 받은 가장 높은 칭호**를 쌓는다 — 「구야국 · 마립간」. 남과 견주는 표 없이 **내 기록 넘기**가 「한 판 더」의 손잡이.
- 7세기 왕 이름은 쓰지 않는다. 「태왕」은 칭호(낱말)일 뿐 광개토 초상·장수가 아니다 → MONEY 「잠긴 칸으로 불안을 팔지 않는다」와 부딪히지 않는다.

### 1차 결정과 하나로
- **판 끝 열전 한 장**(DESIRE ④) = 윗머리 흥망 그래프 · 가운데 「[길] + 칭호」 낙관과 붓 막대 · 아래 장수 셋의 열전과 큰 순간 세 컷 · 맨 아래 「사서는 이렇게 적었다」. 굴리지 않는 한 장(슬라이드 피하기).
- **원수 장부**: 원수가 생길 때 사관이 적고(0획), 갚을 때 3획 — 그래프 아래 붉은 낙관 표.
- **칭호 바뀜**(거서간 → 이사금 → 마립간 · 십제 → 백제): 판 중 칭호가 오르는 순간은 그 계절의 사관 한 줄이 된다.

## 4. 1차 결정과 어긋나지 않나 — 점검

| DESIRE 선 | 여기서 |
|---|---|
| 새 화면 만들지 않음 | 그래프 = 나라 판 한 칸 + 열전 윗머리 · 사관 = 계절 보고 한 줄 + 지난 기록 칩 · 등급 = 끝 화면 |
| 엑셀 금지 | 줄 셋 · 눈금 숫자 없음 · 점수 숫자 없음(붓 획 그림) · 칭호로 말함 |
| 해명 문구 금지 · 연출 위 설명 글 금지 | 사관 한 줄은 이야기 글이지 설명이 아니다. 획 옆에 「점수」라는 말 없음 |
| 그림·아이콘 우선 | 그래프 칩 셋 · 큰일 표 · 붓 획 · 낙관 — 새로 구울 그림은 붓·먹 두어 장(제미나이) |
| 화면 상한(계절에 고르는 장면 둘) | 고르는 장면 0 — 보는 것뿐 · 3획만 「획득!」 한 탭 |
| 판 밖 자산을 잃게 하지 않음 | 휘장 칭호는 쌓이기만 한다 |

## 5. 하나만 고른다면 · 형이 정할 것

**하나만: 「사관의 붓」** — 본기 한 줄 + 붓 획 + 판 끝 스무 칸 칭호.
1. 형의 두 말 가운데 **"매 턴 한 일이 점수로 들어가고 끝에 등급"**이 더 크다 — 그래프는 숫자를 보여 주지만, 사관은 **내가 한 일을 이야기로** 돌려준다(문명 6·올드 월드가 먹힌 자리). 게임 제목 「삼한열전」을 실제로 쓰는 장치다.
2. 판정이 0이다. 끝 화면이 이미 보고 줄에서 큰일을 뽑고 있다 — 꺼내서 계절마다 쓰고 셀 뿐(sim 무관 · A1 안전).
3. 다른 것이 다 여기에 매달린다: 그래프의 큰일 표 · 원수 갚음 · 칭호 바뀜 · 열전 · 휘장의 「내 최고 칭호」.
4. 위험은 문체(CK2의 실패) — 일 종류마다 문장 꼴을 셋씩 두고(같은 일이 같은 글로 되풀이되지 않게), 형이 처음 스무 줄을 읽어 본다.

**둘째: 흥망 그래프** — `lotOfAll` 한 함수 + SVG 줄 셋. 사관 뒤 같은 세션에 붙일 만큼 작다(S~M · 그림 0).

**형이 정할 것**
- Q1 「등급 없음 · 숫자 점수 없음」(META §7-1 · 10-24)을 이번에 바꾸는가 — 안: 점수는 붓 획 그림으로만, 판 끝은 칭호로만, 남과 견주는 표는 없음.
- Q2 스무 칸 이름 — 위 표대로인가, 「성왕」 자리 · 「거서간」을 임금 묶음 맨 앞으로 옮길지.
- Q3 판 끝 말 꼴 — 「칼로 판을 쥔 마립간」처럼 길과 칭호를 한 마디로 묶을지, 지금의 옛 임금 칭호(동명·혁거세…)를 그대로 두고 칭호를 따로 찍을지.
