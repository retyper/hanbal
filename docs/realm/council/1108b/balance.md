## 0. 어떻게 쟀나

- `npm run balance` 는 옛 활터 화살 시뮬(11520판 · 정상 종료)이라 나라 판은 못 잰다 (1108/balance.md §0 과 같음). 나라 판은 `tools/realm-sim.ts`.
- 기본: `node --experimental-strip-types tools/realm-sim.ts --games 96 --seasons 100 --bot planner --as iseo --region yeongnam --tier 1|3 [--set ...]` · 한 묶음 3~6분.
  표의 ± 는 96판 평균의 표준오차. **짐 비율은 96판에서 ±3~4%p 가 소음**이다 (1판 = 1.04%p).
- `--set` 으로 못 바꾸는 것(Q2 의 화친 · Q3 의 잣대)은 **레포 밖 프로브**로 쟀다 (scratchpad · 레포에 안 넣음):
  - `coal-probe.ts` — realm-sim 과 같은 씨앗·같은 봇으로 판을 돌리며 ① 연합이 끝난 뒤 12계절을 갈래별로 지켜보고 ② 위협>0 인 계절 끝마다 우리와 맞닿은/싸우는 이웃의 `leaderOf` 를 세고, 같은 상태에서 잣대를 바꾼 셈(`leaderNow` 를 옮겨 적은 것)을 나란히 본다. `--autoTruce broken|all` 은 연합이 끝나는 턴에 남은 연합 나라와 `makeTruce`(8계절)를 건다.
    검증: 끈 상태의 프로브 판 총계가 realm-sim 48판과 **소수 둘째 자리까지 같다** (적 공세 14.15 · 끝땅 15.92 · 이김 4.2% · 짐 8.3%) — 결정론 그대로.
  - `leave.ts` — 연합 줄(`leave` 의 why · 끝 갈래)을 모이는 중/출정 중으로 나눠 센다.
  - `alt1/`·`alt2/` — `src/` 를 scratchpad 로 통째 복사해 `stance.ts` 의 잣대 한 줄만 바꾼 판 (Q3 실험).
- **봇은 형이 아니다.** planner 는 상단 장사를 안 해 형보다 가난하고(형 #15 s60 집 17255 · 봇 s59 9196), 군세는 이웃 가운데 늘 1등이다(위협≥2 계절의 94.6%). 형은 거꾸로 "군사가 가장 센 남보다 늘 적었다"(1108 README). 이 차이가 Q1·Q3 판정에 그대로 들어간다.

## 4. Q3 — 앞서가는 나라의 잣대와 판 크기

먼저 영남 판에서 이웃이 실제로 보는 판의 크기 (프로브 · 보통 48판 · 위협>0 인 계절 끝 4103번 · 맞닿은/싸우는 이웃의 눈):

| | 위협>0 전체 | 위협≥2 (연합이 설 수 있는 때) |
|---|---|---|
| 우리가 아는 나라 (우리 빼고) | 2.82 | 2.74 |
| 이웃이 아는 나라 (제 나라 넣어) = n | 3.85 | 3.81 |
| 우리 집 몫 · 힘 몫 (이웃의 눈) | 43.0% · 54.4% | 49.1% · 59.6% |
| 우리가 힘으로 1등 | 90.3% | 94.6% |
| 이웃이 우리를 앞서가는 나라로 봄 | 80.0% | 81.5% |
| **집 몫 규칙(richLead)이 결과를 바꾼 때** (힘 몫 < 0.15 ≤ 집 몫) | **0.0%** | **0.0%** |

- **richLead 는 영남 판에서 한 번도 일하지 않는다** (보통·난세 3·cautious 봇 모두 0.0%). n≈4 면 한 나라 평균 몫이 25% 라 힘 몫 15% 는 누구나 넘는다 → 모두가 후보가 되고 도읍 수 → 힘 순으로 가린다. 집이 아무리 많아도 **힘이 1등이 아니면 뽑히지 않는다.** 봇은 힘이 늘 1등이라 티가 안 나지만, 형처럼 군사가 2등인 부자는 이 규칙에 걸리지 않는다.
- 위협≥2 에서 우리가 힘 1등이 아닌 계절(5.4%)만 떼어 보면: 우리 집이 이웃 눈의 1등인 때 64.8% · 그런데 우리를 보는 때는 **17.6%** 뿐 (난세 3: 1등 아님 7.3% · 우리를 봄 12.1%).
- 우리가 힘 1등인데도 남을 보는 나머지 ~13% 는 도읍을 더 쥔 나라(도읍 둘 = 이기는 길 하나 앞)다 — 맞는 판단이라 건드리지 않는다.

물음의 안(문턱을 아는 나라 수로 나누기)과 다른 안을 같은 상태에 대 본 것 (이웃이 우리를 앞서가는 나라로 보는 비율 · 보통):

| 잣대 | 위협>0 | 위협≥2 | 위협≥2 · 우리가 힘 1등 아님 |
|---|---|---|---|
| 지금 (0.15) | 80.0% | 81.5% | 17.6% |
| max(0.15, 1/n) | 80.0% | 81.5% | - |
| max(0.15, 1.5/n) = 1.5/n | 76.8% | 81.0% | - |
| 2/n | 54.1% | 65.5% | - |
| **도읍이 누구보다 적지 않고 집이 1등이면 우리** | 83.4% | 84.9% | **80.3%** |

- **아는 나라 수로 문턱을 올리면 나빠진다** (2/n 이면 80.0% → 54.1%). 문턱은 남만이 아니라 우리 힘 몫에도 걸려, 우리까지 떨어뜨린다.
- 듣는 것은 **줄 세우는 순서**다: richLead 로 든 플레이어가 그 이웃 눈에서 집이 가장 많고 도읍도 누구보다 적지 않으면 힘 순위보다 앞에 세운다.

|---|---|---|---|
| richLead 가 결과를 바꾼 때 | 0.0% | 군세 2등 부자가 걸린다 | 문턱은 그대로 (영남 0.15 · 남쪽 0.1 · 쉰 나라 0.08) |
| 군세 2등·집 1등일 때 이웃이 우리를 봄 | 17.6% | ≥ 70% | **AI 의 눈에서만: richLead 로 든 플레이어가 집 1등이고 도읍이 가장 많은 나라 이상이면 앞서가는 나라** → 80.3% |
| n_known 로 문턱 나누기 | 2/n 이면 54.1% (−26%p) | - | **하지 않는다** |

**판정 Q3: 문턱을 판 크기로 나누지 않는다. 대신 줄 세우는 순서를 바꾼다** (AI 눈 · 도읍 지킴 · 집 1등). 봇으로는 형의 「군세 2등」 판을 재연할 수 없어 판 전체 효과(+9% 공세)는 하한이다 — 형 판 기록으로 다시 볼 것.

## 5. Q4 — 연합군 한 덩어리 결전

| | 측정값 (보통 · 48판) | 목표값 | 제안 변경 |
|---|---|---|---|
| 출정 1번의 적 공세 | 0.92 (출정 59번 · 공세 1.13/판) | - | - |

- 출정은 이미 **한 번에 싸움 한 번꼴**이다. 군대를 하나로 묶으면 그 한 번의 힘만 커져 앗음 37% 가 더 오른다 (지금도 앗음이 막아 냄의 두 배).
