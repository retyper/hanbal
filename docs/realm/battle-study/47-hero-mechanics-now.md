## 0. 한 줄로 (먼저 읽을 것)

1. 본편 전투에서 장수가 하는 일은 **한 곳(`lead` 칸)에 몰려 있다.** 한 합에 무리 셋(앞줄·활·말)이 각각 명령 하나 + **장수 명령 하나**를 낸다(`RoundOrder` Ty:531). 장수 명령 후보는 격려·호궤·비기·각성기·겨루기·사로잡기·퇴각 일곱 가지(`leadOptions` T:487).
2. **장수는 무리에 붙지 않는다.** 코드에 「장수가 앞줄/활/말 어디에 선다」가 없다. 장수는 군 전체(`Side`)에 걸린 값(지휘 `mu`·`tong` → 전투력 · 지략 → 퇴각·낌새)이고, 무리 계산(`groupPower` T:385)에 장수 자리가 없다. **[확인]**
3. **새 전장 엔진(`src/field/`)은 장수 한 명(편마다)** 이고, 장수의 `mu`(무예)는 **sim 이 읽지 않는다**(`LiveSide.hero.mu` 는 받기만 한다 · `src/field/*` 에서 `.mu` 사용 0). 장수 입력은 「자리로 가라」(`g=3` · `OP_MOVE`) 하나뿐. **[확인]**
4. 형이 말한 일곱 낱말은 **전부 코드에 있다.** 못 찾은 것 없음(§1). 단 「샛길 기습」은 이름이 둘이다(장수 비기 `ambush` 와 진군 방식 `night`·`ambush` 표지 — 다른 장치).
5. 새 설계(30·40)가 **말을 안 한 것**이 많다(§4 맨 위): 호궤 · 샛길 기습 · 큰 외침 따위 비기 아홉 종 · 격려 · 선봉 돌파 판 · 부장/총대장 교체 · 원군 장수 · 유물 · 특성 · 저격 · 자객 · 각성기 다섯 기운. 30·40 의 장수는 「스틱 + 자동 공격 + **비기 하나**」다.
6. 키보드: 본편 전투 화면(`battlefield.ts`)은 **키 입력 0개**, 새 시험장은 `1~4`·`Esc`·`Enter/Space` 뿐(장수를 걷게 하는 키 없음), 패드 코드는 `src/` 전체 0줄. 열전만 WASD·Shift·Space·E 가 있다(§5).

## 1. 장치 전수 표

읽는 법: **누가 고르나** = 사람(우리 쪽 플레이어가 깃발로) / 자동(맡김 · AI 가 고름). **적 AI** = 적 쪽 AI 도 쓰는가. 「한 판」 = 한 싸움.
`lead` 칸 명령은 한 합에 하나. 한 번만 쓰는 것은 `ONCE`(T:211: ford · rocks · gate · ram · fire · height · duel · feast · wake). 비기(art)는 `ONCE` 가 아니라 **장수마다 한 번**(`State.artsA/D`).

### 1-C. 비기 아홉 종이 누구에게 붙나(`heroArt` H:140)

순서대로 처음 맞는 것: 해비 각성(선봉) → 특성 명궁(명궁의 한 발) → 무당 핏줄(진중 굿) → 매혹(항복 권유) → 백 사람의 이름(버텨라) → 산사람·물길잡이·밤눈(샛길 기습) → 없으면 **가장 높은 능력치가 `tacArtMinStat` 7 이상**일 때 무예 선봉 · 지략 거짓 퇴각 · 통솔 진을 다잡는다 · 매력 큰 외침. 둘 다 아니면 **비기 없음 = 그냥 북(격려)**. 잔무늬거울을 지니면 무엇이든 진중 굿(S:1163).

## 6. 확인한 사실과 의견을 가른다

### 6-A. 확인한 사실(코드를 열어 봄)

- 형의 일곱 낱말 모두 코드에 있다(§1-A). 못 찾은 것 없음.
- 장수 명령 일곱(격려·호궤·비기·각성기·겨루기·사로잡기·퇴각) + 비기 아홉 종 + 앞줄·활·말 명령 14종(§1-B) = 장수 장치. 합마다 장수 명령은 하나, 무리 명령 셋.
- 장수는 무리에 붙지 않는다. 능력치는 군 전체 전투력(지휘 `leadMul`)과 확률식(겨루기·사로잡기·퇴각)에 들어간다.
- 한 번만 규칙이 다섯 갈래: 장수마다(비기) · 편마다(겨루기·호궤·각성기·땅의 수) · 성공 전까지 무한(사로잡기·퇴각) · 합마다(격려).
- 호궤는 우리 쪽만 쓴다. 각성기도 우리 쪽만. 적 AI 는 격려·비기·겨루기·사로잡기·퇴각·땅의 수·마지막 때를 쓴다.
- 「저격」은 `snipes` 인자를 받는 길만 있고 부르는 화면이 없다.
- 우리 장수는 싸움으로 죽지도 눕지도 않지만 **사로잡힐 수는 있다**(군주 본인 제외).
- 새 엔진: 장수 편마다 1 · 능력치 안 읽음 · 입력은 「자리」 하나 · 쓰러짐·물러남 입력·잠든 기습만 있음.
- 패드 0 · 본편 전투 키 0 · 시험장 키 4종.

### 6-B. 내 의견 **[의견]**

1. **새 설계의 가장 큰 구멍은 「장수 한 명 + 비기 하나」가 본편 장수 명령 일곱 + 비기 아홉 종을 대신할 수 있는가이다.** 본편은 장수의 정체성(비기·특성·각성기)이 싸움 수학에 걸린 곳이 많은데 새 엔진은 `mu` 조차 안 읽는다.
2. 호궤·격려·큰 외침은 「합마다 한 번 고르는 장수 명령」이었다. 실시간에서는 **누가 어떻게 낼지**(단추? 키? 쿨?)가 설계에 없다. 다른 장수(부장)가 무엇을 하는지도 없다 — 새 엔진은 부장 자리가 없고 본편은 최대 10 까지 이론상 올 수 있다. 실제 분포를 모르니 **먼저 `battle-stats.ts` 에 장수 수 칸을 더해 재는 것**을 권한다.
3. 「한 판에 한 번」 규칙(호궤·겨루기·각성기·땅의 수)은 때 문(`gate`)과 맞물릴 수 있다 — 때마다 새 합이 되는 본편과 달리 실시간은 때가 느슨하다. 이 규칙을 「때마다 한 번」으로 옮길지가 결정 사항이다.
4. 샛길 기습은 새 설계에서 **진군 방식 기습**(잠든 시작)으로만 살아 있고 **장수 비기 샛길 기습**은 말이 없다. 두 장치를 합칠지 갈라 둘지는 형이 정할 일이다.
5. 키보드: 본편 전투를 실시간으로 바꿀 때 `lead` 칸 일곱이 키가 하나도 없는 상태에서 출발한다. 새 시험장도 `1~4` 로 칸을 고르면서 **자리 찍기는 마우스뿐**이라 「키보드만으로」는 아직 못 한다. 열전의 WASD·Shift·Space·E 는 가져올 수 있는 선례다(F4b 가 stick/keys 를 새로 쓴다고 했다).
6. 「우리 장수는 사로잡히나」: 코드는 된다. 설계(F4a 3)는 「사로잡기는 적장에게만」이라 적었다. 본편 규칙을 새 엔진이 어떻게 이을지 정해야 한다.
