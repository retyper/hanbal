그림은 원본과 거의 같다(8×8 칸 20,467개 중 40개만 다르고 최대 차 15/255). 그래도 4× 에서 8ms 언저리 — 더 내리려면 2번(구운 띠)과 점 수.
```ts
// 그림자: 정렬 전에 편마다 한 번
ctx.beginPath()
for (…kind 0, 그 편…) { ctx.moveTo(d.x + rx, d.y); ctx.ellipse(d.x, d.y, rx, ry, 0, 0, FULL_TURN) }
ctx.fill()
// 뒤집기: 프레임 처음에 getTransform() 으로 a,d,e,f 를 받아 두고
ctx.setTransform(-TA, 0, 0, TD, TA * d.x + TE, TD * d.y + TF)
ctx.drawImage(src, d.frame * s.cw, 0, s.cw, s.ch, -dw / 2, -s.feet * sc, dw, dh)
```
