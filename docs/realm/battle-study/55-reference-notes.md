# 55. 형이 참고 게임 영상을 보고 적은 것 (2026-11-26) — 가져올 것 · 안 가져올 것

형이 삼국군영전 8 · 드래곤 포스 · 유니콘 오버로드 · 창세기전 · 삼국지 영걸전 · 전설의 오우거 배틀 영상을 보고 한 말을 그대로 모은다. 지금 짓자는 글이 아니다. 넣을 때는 하나씩, 값과 시험을 먼저 적는다(critical-before-building).

## 1. 형의 말 (그대로)
- 좋은 게임들의 공통: 「해야할일이 너무 확실히 보이고 딱 필요한 정보들만 항상보이면서 시각적으로도 수려해. 전투 들어가는 카메라 연출과 이펙트, 분명한 승패, 전투는 연출구경하는맛, 필요할때마다 발생하는 전체화면 설명, 전투전 조합과 배치에 따른 양측 데미지 차.」
- 「공통적으로 적을 대충 때리는 게임은 없어. 유닛 하나가 상대를 공격하면 공격당한 쪽은 싱크 맞게 피격되고 체력 0 되면 죽기도 함.」
- 삼국군영전 8: 「삼국군영전이 우리꺼랑 비슷한게 맞긴하다」 · 병종이 아주 많고 병종별 등급 훈련 · 장수 다섯씩 · 자동 공격이면 스킬도 알아서 · 「잡졸들은 일단 다 죽고 장수들만 5:4씩 남아서 싸움. 이건 좀 이상하네」 · 적장은 늘 사로잡고 참수·석방 · 내정·인사·모략 중신에게 맡김 · 선물로 친밀도 · 「창을 딱 자르게 안 만들고 구름처럼 만들어서 계속 뭉게뭉게 … 정적임을 이렇게 피해서 동적임을 넣다니」 · 코뿔소 부대.
- 「우리는 뭔가 배치하면 뭘 하게 하는지 어떤 효과를 가져오는지도 모르네. 그 옛날에는 어떤 일을 어떻게 시켜서 어떻게 처리했을까?」
- 드래곤 포스: 유니콘 오버로드와 비슷 · 이야기 중심 · 인물마다 컷씬과 연출.
- 창세기전: 전투가 Pathway 식(소수가 다수를 상대하는 턴제) — 「재밌긴 한데 우리 게임에선 반영하기 어려움」.
- 영걸전: 턴제 + 이야기 · 군사마다 병력·사기·공격·방어·책략·경험치 · 레벨과 승급템으로 병종 승급(궁병 15렙 → 연노병). 「싸워본 군대가 실전경험을 쌓는게 중요한건 맞긴한데 우리는 부대를 자유롭게 합치고 분리할 수 있게 되어있잖아. 이건 어떻게 한다...」 · 「우리는 철제무기 강화가 있기는 한데 이게 강해지는 게 체감이 안 됨.」
- 오우거 배틀: 전투에 직접 명령 없음 · 작전 설정과 타로 카드로 개입 · 동료 50명쯤을 레벨로 육성 · 엔딩 여럿(진엔딩의 성취) · 「게임 전체 통틀어서 한 번만 쓰이는 애니메이션 에셋도 있음. 마구잡이 재활용이 아니라 필요한 곳에 제대로 만드는 게 중요하기도 하네」(잡혀가는 사람을 잡으려다 넘어지는 연출).
