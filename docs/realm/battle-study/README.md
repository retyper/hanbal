# battle-study · 본편 전투를 실시간으로 (2026-11-25 시작)

## 형의 말 (그대로)
- 「열전 화면이 게임다워진다는 얘기 들었어. 다음은 본편 전투여야겠는데. 거상처럼 만들어야 되나? 파오캐처럼 만들어야 되나? RTS 같은 느낌으로 해서 아군 진영부터 적 진영까지의 맵을 크게 먼저 일관성 있게 만들어 가지고 기습, 대로에서 만남, 공성 수성, 개울, 수상전, 목책, 목책 해자, 이런 거 다 구현해 두는 게 좋을까? 그리고 기존처럼 군사 지휘는 깃발로 하고 적 군세 파악은 미니맵으로 하고 그런 거지. 정찰 있으면 적 깃발이랑 다음 수도 보여 주는 거고. 그래서 빨리 군사 뽑아서 전투 해 보고 싶게 만드는 거임. 매우 큰 개선인데 이렇게 해야 좀 재밌을 거 같은데 거상이랑 롤을 섞은 느낌으로.」
- 「소스 재활용하기도 좋고 유닛으로 열전에서 쓰던 건물을 추가할 수도 있겠음.」
- 「이건 지금까지 카드로만 하던 게임을 실시간 전투로 바꾸는 거라 제대로 된 설계와 레퍼런스 분석, 클로드 스스로를 지휘하기 위한 단계별로 상세한 일감 나누기와 가이드가 필요함」

## 앞선 결정 (조사 일꾼은 이것을 전제로 읽는다)

- 11-23 형 구상(`docs/realm/MEGAHIT.md` 끝): 깃발로 군사 자동 지휘 + 장수로 뛰어들어 무쌍 + 적 장수를 만나면 1:1.
