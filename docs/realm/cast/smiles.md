# 웃는 초상 — 목소리에 웃음 결을 입힐 사람들 (형 11-02)

형이 직접 초상을 보고 적은 웃음 결. 장수 전용 성우(src/ui/realm/voice-hero.ts)의 `style` 과 `<laugh>` 자리를 정할 때 이것을 따른다.
형: "웃음기 있는 이미지들이 있는데, 활짝 웃는 천진난만한 웃음이 있는가 하면 요염한 웃음도 있고 · 잘 반영해서" · "여캐 이쁘고 야시시한 캐릭터들 우선적으로".
