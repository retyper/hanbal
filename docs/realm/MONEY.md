# 과금 — 무엇을 팔고 무엇을 안 파나 (MONEY)

> 2026-10-23 형: *"규칙6은 바꿔도 돼. 과금 넣어"* · *"난 재밌게 만들기만 하면 돼. 과금도 고려하면서"* · *"니가 직접"*.
> 정한 길: 다섯 역할 회의(역사가·재미 설계자·밸런스·수익·팔리는 말)와 세 반론을 거친 의장 결정 — docs/realm/CUSTOMS.md §7.

## 0. 한 줄

**땅·시대·이야기는 판다. 힘·시간·확률·편의·불안은 팔지 않는다.**
돈을 낸 사람은 **더 많이 놀 거리**를 사고, 안 낸 사람과 **같은 판에서 같은 세기**로 이긴다.

## 1. 파는 것

| 무엇 | 어떻게 | 언제 |
|---|---|---|
| **본편 한 번 사기** | 스팀 유료 · 모바일은 무료로 받아 **배우는 판 + 1·2장 + 작은 판**을 해 본 뒤 한 번 결제로 연다 | 스토어 출시 때 (BUILD Q11 앱 껍데기) |
| **시대 확장 묶음** | 땅이 아니라 **시대**로 자른다. 첫 묶음 「쇠와 말의 시대」(4세기 — 개마 · 판갑 · 가야 연맹 · 광개토), 다음 「바다」(우산국 512 · 먼 뱃길 · 주호) | 본편 뒤 |
| **곁벌이 (게임 밖)** | 텀블벅 후원(웹판에만 고리) · 풍습 도감 화집 · 지도 포스터 | 형이 원할 때 (그림의 상업 약관 · 소리 출처 CC BY·공공누리 1유형 확인) |

- 부여·고구려·옥저·동예는 **반드시 본편**에 둔다 — 북녘을 따로 팔면 동북공정 틀로 읽힐 수 있다.
- 확장의 풍습·병종은 **그 확장 땅의 나라에서만 건너온다**. 본편 도감·후보에 잠긴 칸을 보이지 않는다(불안을 팔지 않는다).
- 묶음 사이 이김 폭은 시뮬로 지킨다 (확장 나라가 본편 나라를 누르지 않게).

## 2. 팔지 않는 것

- 풍습·칸·병종 **단품** · 셋 가운데 하나 **다시 뽑기** · 장수 뽑기(가챠)
- **시간 줄이기** (원정·혼인·기르기 시계) · 재상·빨리 넘기기 같은 **편의**
- 보상형 광고 · 시즌 패스 · 구독 · 출석·연속 접속
- 꾸밈(깃발 무늬·초상 옷)은 **미룬다** — 혼자 하는 게임이라 수요가 약하고 그림 크레딧·일장기 검수 짐이 크다

## 3. 지금 코드에 넣는 것 / 안 넣는 것

- 넣는다: 나라·판·풍습 자료의 `pack` 꼬리표 (지금은 모두 `'base'`) · 판 고르기 화면의 잠금 틀 · 개발 스위치(형이 전부 열어 볼 수 있게)
- 시뮬(src/realm)은 **산 판인지 모른다** (결정론 A1) — 잠금은 화면(판 고르기)에만 건다
- 넣지 않는다(형의 일): **결제 사업자 계정 · 키 · 약관 동의 · 실제 결제 시험**. 코드에는 키를 넣을 자리만 둔다
- 웹(github.io)에서 이미 열린 것은 거두지 않는다

## 4. 돈 없이도 다시 하게 하는 것 (본편의 힘)

- 풍습 도감 · 연대기가 지어 준 나라 이름 도감 · "이 나라로 이겼다" 휘장 · 세기(촌장~천손)
- 오늘의 난세 — 같은 시드로 나라 하나와 건너올 풍습 셋. 겨루는 표 없이 내 기록만

## 5. 스토어 첫 줄

**"광고 없음 · 뽑기 없음 · 한 번 사면 끝"** — 팔리는 말 렌즈가 이것을 이 게임의 약속으로 본다.
