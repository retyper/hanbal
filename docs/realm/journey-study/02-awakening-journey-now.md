# 02 · 각성과 장수 기르기 여정, 지금 어떻게 도나 (현황 지도 · 2026-11-25)

> 설계 연구 `journey-study` 의 현황 지도 02. 읽기만 했다(코드·데이터·문서 수정 0 · git 0).
> 형의 물음(11-25): 「판마다 난이도를 정할 수 있게 해야 하나?? 그래서 고난이도를 다 깨면 각성하게 해야 하나?? … 각성 컨텐츠 여정 확정은 자꾸 고치게 돼 ㅜㅠㅠ 진짜 잘 만들고 싶어서야.」
> 표시: **[사실]** 오늘 내가 파일을 열어 본 것(파일:줄) · **[옮김]** 남이 확인한 것을 옮김(내가 다시 안 돌림) · **[의견]** 내 판단 · **못 잼** = 잴 방법이 없었음.

## 다섯 줄 요약

1. **[사실]** 지금 제품에서 장수 각성은 **한 길뿐**이다: 그 장수로 열전 3스테이지 「목책 돌파」를 깬다. 본편 불꽃·8분 시련은 코드에서 닫혀 있다(`legacyAwakeningOpen` 0). 한 번 깨면 그 사람은 **계정 영구 각성**(출전부터 +35% 힘·각성 모습), 토글은 모습만 끈다.
2. **[사실]** 본편 불꽃(투지 자격)은 이제 각성한 장수의 각성기 연료일 뿐이다. 「본편 불꽃이 차면 투지로 힘 +1」(11-18 결정 2)은 11-21 에 사라졌고, **본편에는 투지가 없다.** 투지는 열전 판 안 막대 하나다.
3. **[사실]** 열전에는 **난이도 고르기가 없다.** 난이도 사다리는 스테이지 다섯(숲 → 여울 → 목책 → DLC 둘)이고, 본편에는 판을 열 때 정하는 「난세 단계 1~10」이 따로 있다. 둘은 각성과 이어져 있지 않다.
4. **[사실]** 「첫 각성 = 플레이 10시간대」(11-18)는 코드에 없다. 첫 각성의 최소는 성공한 20분 판 셋(숲·여울·목책 = 약 1시간), 현실은 상점 금 모으기가 낀 수 시간. 사람 시간은 **못 잼**. 「본편 장 N개를 깨야 도깨비가 뜬다」는 안 만들어졌다.
5. **[사실]** 자꾸 바뀐 것은 **「각성을 어디서 여는가」**다. 본편 연승(10-31) → 본편 시련(11-15) → 열전 막대(11-17) → 열전 목책 도깨비(11-18~21). 반대로 **안 바뀐 것**은 「열전이 기둥」「토글은 모습만」「진각성은 DLC」「우리 장수는 안 죽는다」이다.

### 2-1. 각성까지 몇 판·몇 시간? (어림 · 사람 기록 없음)

**[사실]** 판 수의 바닥
- 첫 장수·첫 각성: 숲 승 + 여울 승 + 목책 승 = **성공한 20분 판 3개 = 약 60분**(봇 이긴 판 끝 19:02~19:26). 목책이 본편 표적이면 숲·여울을 건너뛴다(1-2) = **최소 1판 약 20분**.
- 본편 안에서는 장수 전체 한 달에 열전 한 번이라, 본편에서 각성 N명 = 본편 N달 이상.
- 장수 하나당 목책 한 판. 이름난 장수 약 217명(`HERO_BUST`)이면 전원 **약 70시간**[옮김 · `study-20261118/31-ASK.md` 1번 · 217은 01 장에서 셈].

**[옮김]** 봇 승률(11-15 · REACT=.5 · 묶음 넷 × 씨앗 2 = 8판, `RAID-KITS-20261115.md:109-115`): 상점 0 → 숲 4/8 · 여울 0/8 · 목책 0/8 / 7할 → 8/8 · 8/8 · 7/8 / 다 채움 8/8 전부. 이후 목책에 진짜 목책(56-C)이 들어가 상점 5할 이김이 4 → 3(`docs/BALANCE.md:2259`). **사람 손으로는 한 판도 안 쳐 봄**(같은 문서).

**[사실 · 어림]** 상점 값: 다 사면 약 4만(`params.ts:1318-1330` 주석 37,335 → `BALANCE.md:2152` 42,486). 한 판 금(상점 0 · 숲 이김 약 1,312 · 여울 이김 약 3,390 · `params.ts` HAEBI_REFUND 주석 11-19). 7할(약 3만)이면 숲 약 23판 또는 여울 약 9판의 금. **사람이 이 길을 가는 시간은 못 잼.**

**결론 [의견]:** 코드가 주는 첫 각성은 「1시간 안 최소 ~ 상점 노가다 몇 시간」이고 **10시간대 목표를 받치는 장치는 없다**(장 조건 N 미구현). 반대로 목책 표적이면 20분에도 된다. 폭이 큰 것이 문제다.

## 6. 형의 물음에 이 지도가 말해 주는 것 (의견 · 설계는 다음 장)

**[의견] 지도에서 보이는 비어 있는 곳**
