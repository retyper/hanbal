## 0. 열 줄 요약 (설계를 가르는 사실)

1. [옮김→사실 일부] 열전에는 판마다 난이도 고름이 없다. 난이도는 스테이지 셋(숲 → 여울 → 목책)이고 앞 판을 깨야 열린다. `STAGE_ORDER` 의 설원·산성은 DLC 꺼짐(meta.ts:27 확인).
2. [옮김] 「초반 쉬움」은 **5분 한정** 측정이다. 01 의 서 있는 봇은 숲 5분 최저 체력 평균 82%(상점 0)인데, 02 가 옮긴 20분 봇 승률은 상점 0 에서 여울 0/8 · 목책 0/8 이다. 쉬움은 앞 5분, 벽은 뒷판이다. 둘 다 사실일 수 있다.
3. [사실] 항아리·솟대·봉수대·우물은 체력 없는 영구 벽이고(build.ts:22), 체력을 깎는 줄은 haebi.ts 에서 1669·1920 둘뿐이라 정예·두목은 설치물을 못 친다. 01 의 이 주장은 다시 열어 맞았다. 형이 말한 꼼수는 코드로 성립한다.
4. [사실] 각성의 문은 지금 **목책 돌파 하나**다(link.ts:17,22 · params.ts `legacyAwakeningOpen` 0). 본편 불꽃·8분 시련은 닫혀 있다. 힘(+35%)과 모습이 한 문에서 같이 열린다.
5. [사실] 1차 각성 문(`DEMON_STAGE`)과 진각성 자격(`SEAL_STAGE`)이 둘 다 `palisade` 다. DLC 를 켜면 진각성 문이 비어 있다.
6. [사실·옮김] 「첫 각성 = 10시간대」(11-18)를 받치는 코드는 없다. 최소는 성공한 20분 판 셋(약 1시간), 목책이 본편 표적이면 1판. 사람 손으로 친 시간 기록은 없다.
7. [사실] 바깥 사례를 다시 열어 보니 난이도 사다리 쪽 사실(Eclipse 여덟 단계·보상은 표식뿐, Brotato 위험 0~5 규칙)은 맞다. 그러나 「사다리 완주가 힘을 영구히 올린다」는 사례는 어느 장에도 없다. 우리는 이미 힘 +35% 를 묶었다. 선례가 없는 쪽을 가고 있다.
8. [사실] DNF 「각성 레벨 48」은 2010 기사 한 건에서만 나온다. 현재는 50/75/100 으로 적힌 곳이 있다. 13 의 뼈대 1(레벨 N + 전용 관문 + 컷인)의 「전용 던전·컷인」 부분은 [기억]이다.
9. [의견] 아무도 안 본 큰 구멍: 열전은 본편에서 장수 전체가 한 달 한 번(`raidMonthAll` 1, params.ts:4045)이다. 각성이 열전에 걸려 있으니 **각성 속도는 본편 달 수**가 정한다. 시간 계산은 이 제한을 안 넣었다.
10. [의견] 출시 2027-03 · 새 시스템 동결 · 체험판 = 배우는 판 + 1장 + 열전 숲. 「판마다 난이도」「사다리」「새 적 역할」은 모두 새 시스템이다. 체험판의 첫인상이 「서 있어도 안 죽는 숲」이라는 점이 가장 급하다.

## 5. 설계안 셋이 반드시 답해야 할 빈칸 금지 목록

설계안이 이 칸을 하나라도 비우면 심사에서 반려한다.

### 5-1. 상태 표
- 장수·스테이지·단계(있다면)별로 **무엇이 저장되나**: 열린 단계 · 최고 클리어 단계 · 각성 여부 · 토글.
- 각 상태가 바뀌는 사건 표(이김 · 짐 · 시간 초과 · 중간 종료 · 옛 저장).
- **옛 저장 이주**: 이미 `meta.heroes` 에 palisade 가 적힌 장수는 새 규칙에서 어떻게 되나(각성 유지 · 형의 판 11-22 이전 기록).
- 판마다 난이도가 있다면 **어느 값이 기록에 남나**(기록 재생·결정론 A1).

### 5-2. 모드별 동작
| 모드 | 답해야 할 것 |
|---|---|
| 열전 독립(첫 화면) | 단계 고르나 · 각성 장수 쓰나 |
| 본편 표적으로 온 열전(한 달 한 번) | 단계 고정? 앞 스테이지 건너뜀(raid-bounty 11-23) 규칙과 사다리의 관계 |
| 배우는 판(말갈기 빌린 힘) | 그대로 두나 · 새 규칙에서 어떻게 보이나 |
| 영웅전·도감 | 각성 표식 · 단계 표식이 어디에 |
| 체험판 | 열전 숲만. 새 규칙이 숲에서 무엇을 바꾸나 |
| DLC 설원·산성 | 진각성 문 새 자리 |

### 5-3. 비용 (단위 필수: 형의 일수 · 새 그림 장수 · 시험 수 · 시뮬 시간)
- 코드 변경 파일 수 · 새 시스템인가 기존 값 손질인가(동결 판정).
- **새 그림·영상·컷인 장수.** 「장수마다 각성 그림은 이미 있음」을 전제로 얼마나 더 필요한가.
- 시험·밸런스 시뮬 재측정 범위(숲·여울·목책 × 상점 0 / 절반 / 가득 · 5분과 20분 둘 다).
- **출시(2027-03) 안에 끝나나 · 뒤로 미룬 쪽은 무엇이 비나.**

### 5-4. 물을 것의 기본값
- 4-1 의 Q1~Q6 마다 설계안이 **기본값 하나**를 적는다. 형이 「니가 해」 하면 그대로 가는 값.
- 각 기본값에 **되돌리는 비용**(틀렸을 때 몇 일)을 적는다. 형의 가장 큰 고민이 「자꾸 고치게 됨」이므로 되돌리기 쉬운 쪽을 기본값으로 삼는다 [의견].

### 5-5. 숫자 근거
- 목표값마다 「무엇으로 잴지」: 서 있는 봇 5분 최저 체력 · 20분 승률 · 사람 판. 「느낌상」 금지.
- 5분과 20분을 둘 다 말하기. 초반 쉬움과 목책 벽이 같은 문제의 양끝이다(01 §5-4).
- 사람 판 근거가 없는 숫자는 [의견]으로 적고 **측정 계획**을 붙이기.

### 5-6. 동결·방침 충돌 확인표 (설계안마다 예·아니오)
| 방침 | 출처 |
|---|---|
| 우리 장수는 싸움으로 안 죽는다 | player-heroes-never-die |
| 져도 성장(소울류) | hero-growth-souls |
| 전투는 운보다 통제(숫자로 예측) | battle-control-not-luck |
| 확실히 지는 고름을 숨김 | 같은 메모리 |
| 힘·시간·뽑기·광고는 팔지 않는다 | megahit-plan · MONEY |
| 새 시스템 동결 · 체험판 범위 | launch-plan-march |

### 5-7. 설계안이 답해야 할 형의 물음 네 줄
1. 건물이 부서져야 한다 → 어떻게, 몇 초에, 누가 부수나?
2. 초반이 쉽다 → 몇 분에 무엇이 와서 **피할 이유**가 되나?
3. 판마다 난이도를 정하나 → 처음부터? 깨서 열고 고름? 고르면 무엇을 얻나?
4. 고난도를 깨면 각성하나 → 무엇을 몇 번 깨야 하고 힘은 어디에 묶이나?
