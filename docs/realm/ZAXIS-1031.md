# 지도의 z축 UI (10-31)

> 형 10-31: "핸드폰은 작기 때문에 … 관련된 인터페이스만 샥샥 골라 보여주고 필요한 건 더 크게 새로 띄워주고
> 필요 없는 건 없애주는 … 모바일에서 공간 활용은 xy 축이 아니라 z축으로 … 게임판 맵에 그런 고도화가 필요함."
>
> 한 줄: **안 만지면 땅·고을·이름·우리 군대·위협만. 누르면 그 대상에 붙은 것만 튀어나왔다가 걷힌다.**
> 설계만 적는다. 코드는 아직 안 고쳤다.

## 2. 쉴 때 보일 것 / 누른 뒤로 숨길 것

쉴 때 (아무것도 안 고른 상태, `root.rest`)
- 땅빛 · 길 · 고을 그림 · 이름(깃발 그림 + 이름 한 줄, 지금 지명은 뺀다)
- 우리 군대 말 (`명령?` 물음 포함) · 다가오는 적 화살 · 위협 `⚔` · 적 말
- 규칙 그림은 남긴다: 안개·언 해자·연기·불탄 고을 (규칙은 지도에 보이게 · GAP §11)
- 판 둘레: 위 띠 · 다음 계절 · 아래 탭 · 이번 계절 칩. 깃발 줄은 한 줄로 접은 알약.

누른 뒤로 숨길 것 (그 고을·그 군대를 눌렀을 때만 그 하나에 뜬다)
- 관계 칩 `.lbr` · 특산 칸 `.lbg` · 정찰 군세 `.lbf` · 우리 군사 수 `.men` · 장수 얼굴 `.gov` · 붐빔 `.crw`
- 빈 땅의 `＋마을`·`군대만 가면`·까닭 칩: 개척단·군대를 골랐을 때만 (지금은 고른 게 없을 때 다 뜬다, app.ts:1486)
- 가까이 당기면(배율 높음) 특산 칸·관계 칩은 쉴 때도 보인다. 멀리선 숨긴다 (줌 단계로 거르기).

## 3. 누르는 것마다

| 누른 것 | 튀어나오는 것 | 어디에 | 걷히는 법 |
|---|---|---|---|
| 우리 말 | 갈 곳 칩이 가까운 것부터 차례로 퐁 · 다른 고을은 흐려짐 · 아래에 작은 띠(장수 얼굴·사람 수·`머문다`) · 장수 대답 | 칩은 고을 위, 띠는 화면 아래 붙박이 | 같은 말 다시 · 빈 곳 누름 · 명령을 내리면 띠가 `출발` 한 번 튀고 걷힘 |
| 우리 말 꾹 | 설명 창: 장수·병종 그림·사기·지략 | 손가락 위 (못 들어가면 아래) | 손 떼고 잠깐 뒤 |
| 적 말 | 작은 카드: 나라 깃발 · 군세 범위 · 아는 장수 얼굴 · 가는 곳 화살 굵게 | 말 곁 (화면 밖이면 반대편) | 다른 곳 누름 · 몇 초 뒤 저절로 |
| 적 말 (우리 군대 고른 채) | 지금처럼 그 고을로 보낸다 (6274~6278) | | |
| 우리 고을 | 고을 둘레에 동그란 단추 서너 개 (`장수`·`개척단`·`군대`·`자세히`) + 이름표에 특산 칸·장수 얼굴·사람 수 펼침 | 고을 둘레 | 빈 곳 누름 · 다른 것 누름. `자세히` 만 지금의 큰 판을 연다 |
| 남의 고을 | 작은 카드: 깃발 · 관계 · 정찰 군세 · 특산 + 단추 `척후`·`사신`·`자세히` | 고을 곁 | 위와 같음 |
| 빈 땅 | 개척단이 닿으면 큰 단추 하나 `개척단 보내기` · 못 닿으면 까닭 한 줄 · 군대만 가면 되는 곳이면 그 말 | 그 땅 위 | 위와 같음 |
| 빈 바다·아무것도 없는 곳 | 모두 걷혀 쉴 때로 | | |

어느 것을 골라도 판 둘레의 깃발 줄·목표 띠·길 보기·＋－ 단추는 흐려져 물러난다 (`sel-open` 이 이미 있다, app.ts:5549).
알림·카드는 반드시 걷힌다: 저절로 · 눌러도 · 값이 깨져도.

## 4. 전투 화면에서 가져올 것 (src/ui/realm/battlefield.ts)

- **설명 창 `.wtip`**: CSS 2681~2695, 열고 닫기 3676~3690. 작은 상자의 opacity+scale 전이, `pointer-events: none`. → 적 말 카드.
- **누르는 동안 창 `.whold`**: CSS 2745~2747, 자리 잡기·걷기 3789~3807 (손가락 위, 화면 안으로 끼움, `warHoldLingerMs` 뒤 걷힘). → 말·고을 꾹 누름.
- **꾹 누름 판정**: 4069~4090 (`warTipHoldMs` · 움직이면 취소 `warTipSlop` · 진동 8ms) + 뒤따르는 click 삼키기 4066, 4127.
- **곁에 뜨는 고르기 판 `.wfpop`**: CSS 2706 + `wfpin` 2742 (0.16초 올라옴), 바깥 누르면 닫힘 4129. → 고을 둘레 단추·작은 카드.
- **아래 붙박이 완료 띠 `.wready`**: 3647~3672. → 군대 고른 뒤의 아래 띠.
- **가운데 한 번 튀는 그림 `.wb0pop`**: CSS 1926~1930, 지우기 3762. → `출발`·`개척단 보냄`.
- 판 카드 차례로 펼치기 `deal` (app.ts:5588~5593) 는 이미 지도 판에 있다. 갈 곳 칩에도 같은 지연을 준다.
- 숫자는 `src/tune/params.ts` 의 `P.realm.map*` 로 새로 둔다 (규칙 3). 전투 것(`war*`)을 같이 쓰지 않는다.

## 5. 나눠 짓기 (하나씩 올려도 판이 돈다)

폰 그래픽 한도: **화면 가득한 층(.mapwrap · 땅빛 svg · 판 둘레)에 filter 애니·transform 금지.** 움직임은 작은 칩·카드의
opacity 와 작은 scale 만. 흐리게 하는 것도 고을 하나하나의 opacity 로 (filter: grayscale 금지).

1. **적 말 카드** (1시간). `foetok` 처리를 만들고 `.wtip` 꼴 카드를 말 곁에. 지금 빈 곳이라 다른 데를 안 건드린다.
2. **쉴 때 다이어트** (1~2시간). 고른 게 없으면 `root.rest`. CSS 만으로 2장의 숨길 것을 숨긴다 (기존 `hide-*` 와 같은 길).
   줌 단계 클래스 `z-far` / `z-near` 를 하나 더 두고 가까이선 특산·관계를 살린다. 360·375·390·412 폭으로 찍어 본다.
3. **고르면 둘레가 물러난다** (1시간). `sel-open`·`sheet-open` 때 `.legend .goalb .roadkey .zbtns` 를 opacity 0 + 누름 막기.
   갈 곳 칩을 거리 순으로 지연 두고 퐁.
4. **꾹 누름 설명 창** (1~2시간). 전투의 `showHold`·꾹 누름 판정을 작은 공용 파일로 빼서 지도와 전투가 같이 쓴다 (craft).
   지도는 끌기(zoom.dragged)와 겹치니 움직이면 바로 취소.
5. **고을 둘레 단추** (2시간). 첫 누름은 둘레 단추 + 이름표 펼침, `자세히` 만 큰 판. 남의 고을은 작은 카드.
   **배우는 판은 지금처럼 곧바로 큰 판** (튜토리얼 단계가 고을 누름 → 판을 기다린다, app.ts:5925~5933).
6. **빈 땅 한 단추** (1시간). 개척단·군대만 가면을 그 땅 위의 큰 단추 하나로. 까닭 칩은 누른 땅에만.
7. **소리·떨림 마무리** (1시간). 튀어나올 때 작은 소리 `tapSlot`, 걷힐 때는 소리 없이. 오버액션은 결과(출발·점령)에만.

각 단계 뒤: `npm run typecheck` · `npm test` · 폰 폭 네 가지 사진 · 화면 글은 josa-lint · dash-lint 0곳.
