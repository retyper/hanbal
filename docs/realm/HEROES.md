# 장수 첫판 (R2 앞당김, 2026-10-18)

> 형: *"장수들은 육각형이나 7각형 이런거로 능력치 매핑 이런게 있어야 할거같고, 팰월드처럼 특성부여해서 농사잘짓게하거나
> 매혹을 잘하게하거나 그런거 있어야 하는거 아냐? 수치로든 패시브 특성으로든"* · *"난 게임하면서 적장을 한번도 본적이 없네"* ·
> *"내가 군주라면 군주이미지는 어딨고 적국 군주는 어디서 보는겨"*
>
> SYSTEMS §5 의 설계(능력치·특성·일·회유)를 처음으로 짓는다. 넷이던 능력치를 **여섯**으로 늘린다 — 육각형 한눈에.
> 숫자는 `P.realm` 에, 특성의 글은 `data/traits.ts` 에. 이 문서가 계약이다.

## 1. 능력치 여섯 (1~10) — 육각형

| 이름 | 한자 | 하는 일 |
|---|---|---|
| 무예 | 武 | 이끄는 군대가 맞붙을 때 (지휘 L 의 절반) · 졌을 때 사로잡히거나 죽지 않고 빠져나올 확률 |
| 통솔 | 統 | 지휘 L 의 나머지 절반 · 큰 군대일수록 무게가 커진다 · 사기가 덜 꺾인다 |
| 지략 | 略 | 기습·정찰·들킴 (지금의 략 그대로) · 맡은 고을의 경계 |
| 내정 | 治 | 맡은 고을의 수확 · 집이 느는 빠르기 · 개척한 땅이 크는 빠르기 |
| 매력 | 德 | 사신을 받아 줄 확률 · 포로 회유 · 맡은 고을 장정 |
| 궁술 | 弓 | 이끄는 군대의 궁수 힘 · 저격판(R2)의 자동 판정 |

- 화면에는 **두 글자**로 쓴다 — 무예·통솔·지략·내정·매력·궁술 (형: "한글자로 하지말고 두글자로", `prose.STAT_NAME`).
- 코드의 칸 이름: 지금의 넷(`mu` · `ryak` · `chi` · `deok`)은 그대로 두고 **`tong`(통솔) · `gung`(궁술)** 을 더한다. 옛 장수의 통·궁은 판 데이터에 새로 적는다.
- 무명 장수 합 = 21~33, 명장 = 33~48 (SYSTEMS §5-1 의 넷 기준 14~22 · 22~32 를 여섯 칸으로 늘린 값).

## 2. 특성 — 팰월드의 패시브

장수마다 0~3개. 등급은 오방색(SYSTEMS §5-2). **한 문장으로 무엇을 하는지** 말할 수 있어야 한다.
`Hero.traits: string[]` — id 목록. 효과는 엔진이 id 로 찾는다.

## 3. 일 — 장수를 고을에 맡긴다 (팰월드 거점, SYSTEMS §5-8)

- 장수는 **군대를 이끌거나**(지금) **고을을 맡는다**(새로). 둘 다는 안 된다.
- 새 Order `{ kind: 'assign'; hero; node | null }` — 제 고을에 맡긴다 / null 이면 맡은 자리를 떠난다(그 고을에 머무는 제 군대가 있으면 그 군대를 이끈다, 없으면 그 고을에 혼자 머문다).
  맡긴 장수는 그 고을에 있어야 한다(같은 고을에 머무는 군대에서 빼내거나, 이미 그 고을에 혼자 있거나). 이동은 군대와 함께.
- 맡은 고을에 치·략·덕과 특성이 걸린다 (§1·§2 표).
- `Hero` 에 `post: string | null` (맡은 고을).

## 4. 장수를 얻는 길 — 첫판

1. **포로 회유** (SYSTEMS §5-4·§5-5) — 사로잡은 장수를 몇 계절에 걸쳐 회유한다. 곡식이 들고, 맡은 장수의 덕·매혹이 빠르기를 정한다.
   Order `{ kind: 'persuade'; hero; by: hero | null }` 한 번이면 계속 진행, 다 되면 우리 장수 (보고 줄 'recruit').
2. **떠돌이 인재** — 해마다 봄에 한 명쯤 우리 고을 하나에 나타난다(굴림 `wanderer:<season>`). 곡식을 내면 들인다, 안 내면 다음 계절 다른 나라로 간다.
   나라마다 처음 장수도 두셋으로 늘린다 (군주 + 장수 하나둘).
3. 장수 그림은 `public/realm/bust/` 의 168장 가운데서 고른다 (art.ts HERO_BUST). 떠돌이는 정해진 목록에서.

## 5. 화면

- **장수 탭** (정찰 탭 자리 — 정찰은 고을을 눌러 한다): 우리 장수 목록 → 누르면 **장수 카드** (명치판 크게 · 육각형 · 특성 칩 · 지금 하는 일 · 맡기기).
- 적장도 카드로 본다: 싸움 카드의 얼굴을 누르면, 외교 탭의 군주 얼굴을 누르면. **본 만큼만** — 싸워 본 장수·정찰한 고을의 장수는 능력치가 보이고, 아니면 얼굴과 이름만.
- 육각형은 SVG — 우리는 금빛, 적은 붉은빛. 두 장수를 겹쳐 보는 비교는 다음 판.
