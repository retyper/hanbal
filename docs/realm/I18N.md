# I18N — 영어(그다음 일본어)로 내는 길

MEGAHIT 기둥 ③ 「세계로」의 바닥. 한국어 출력은 지금과 **글자 하나 다르지 않게** 두고, 영어를 얹는다. (2026-11-11 틀 + 첫 화면 시범)

## 설계

- `src/i18n/lang.ts` — 말 고르기. `?lang=en|ko` > `localStorage['hanbal.lang']` > `navigator.language`(브라우저에서만 · 노드 시험은 늘 ko) > `ko`. 순수 함수 `pickLang` 을 시험한다.
- `src/i18n/ko.ts` — 원본 표. `as const` 객체라 키 오타는 타입 오류. `Key = keyof typeof ko`.
- `src/i18n/en.ts` — `Partial<Record<Key,string>>`. 비면 한국어가 나간다(빈 화면 없음). 일부러 비워 둔 키는 `PENDING_EN` 에 적는다.
- `src/i18n/index.ts` — `t(key, vars?)`. 자리표:
  - `{name}` 그대로 넣기
  - 한국어 `{name|이/가}` 받침 조사 — 기존 `josa()`(src/realm/data/prose.ts) 그대로
  - 영어 `{n|day|days}` 하나·여럿 (`n === 1` 이면 앞). 어느 표의 글이냐로 규칙이 갈려, 영어가 비어 한국어가 나가도 조사는 맞다.
- 말 바꾸기: 첫 화면 「더 보기」 맨 위 언어 줄(한국어 / English). 누르면 저장하고 주소의 `?lang=` 을 지운 채 다시 연다(모든 화면이 한 번에 갈아입게).
- `src/sim` 은 i18n 을 읽지 않는다(결정론). 판 상태에는 말이 들어가지 않는다 — 글은 그릴 때 만든다.

## 글 하나 더하기

1. `ko.ts` 에 `'화면.쓰임': '지금 글'` 을 넣는다. 화면에서는 `t('화면.쓰임', { n })`. 숫자·이름 뒤 조사는 손으로 붙이지 말고 `{name|이/가}`.
2. `en.ts` 에 영어를 넣는다(번역투 말고 영어로 자연스럽게). 못 하면 `PENDING_EN` 에.
3. `npm test` — tests/i18n.test.ts 가 키 짝·자리표 짝·긴 줄표를 본다.
4. HTML 에 들어가는 이름은 `esc()` 한 것을 vars 로 넘긴다(옛 코드와 같은 자리에서 esc).

영어 문체: 삼한(마한·진한·변한)은 한반도 남부의 연맹이다 — 중국의 속국처럼 쓰지 않는다. 고유명사는 국어의 로마자 표기법(Mahan, Jinhan, Byeonhan, Saro, Baekje). 화면 글에 긴 줄표(—) 금지. 한국어 시스템 글은 합니다·하세요 체.

## 시범으로 옮긴 것 (키 52개)

첫 화면(로고 대체 글 · 이어 하기 카드 · 새 게임 · 불러오기 · 영웅전 · 단련터 · 나의 역사 · 몇 분 전), 「더 보기」 설정(그래픽 · 소리 크기 · 설치 · 활터 · 연습 싸움 · 기록 내보내기 · 로그인), 판 고르기 머리와 경고, 나라 상세의 시작 단추.
**아직 한국어인 것**: 계절 이름(seasonLabel, `1년 봄`), 판·나라·장수 이름과 이야기(내용 데이터), 로딩 막대의 도움말, 판 안의 모든 화면.

## 단계 계획 (1인 개발 · 번역은 AI 초안 + 형 눈 · 어림)

1. **UI 껍데기** (~2주): app.ts 의 단추·탭·패널·알림·튜토리얼 글, quality·sound·savebox 등. 글 3,000~4,000 조각. 병목은 문자열을 t() 로 빼는 기계적 일 — `{name|이/가}` 같은 조사가 낀 템플릿이 까다롭다. 끝나면 「영어로 첫 판 끝까지」가 된다.
2. **계절·보고·전투 말** (~1.5주): prose.ts · seasonLabel · reportText · 싸움 보고. 한국어 어순에 맞춘 문장 조립(`{A}이 {B}를 쳐서…`)은 영어에선 문장 틀 통째로 다시 짜야 한다. 가장 손이 많이 간다.
3. **이벤트·장수 대사·카드** (~3주): woo-talk(약 5,000) · cards · hire-lines · council-*. 분량이 가장 크나 기계적. 사극체는 영어에서 문어체로 한 단계 올려 일관되게.
4. **이름** (~1주): 78국 · 장수 · 지명 로마자(Revised Romanization) 표 하나 + 한자·사료 용어 주석(삼국사기 Samguk Sagi 등).
5. 일본어는 같은 키 틀에 `ja.ts` 하나만 얹는다(복수 없음, 조사 규칙 불필요). 글꼴(Gowun Batang 등)은 언어별로 갈아 끼울 것.

목소리는 한국어 그대로 두고 자막으로 낸다(대사 글자는 3단계 표를 재사용). 긴 영어 글은 단추 폭을 넘기기 쉬워 화면마다 390px 로 찍어 본다(tools/phone-shot.ts).
