# 캠페인 — 삼국의 새벽 (CAMPAIGN)

> 2026-10-22 형: "문명처럼 뭔가 캠페인도 있으면 좋지 않을까 … 한국사 역사적인 것들 가지고 구성해서. 특수한 승리조건을 가지고 하는 게임 같은 거?"
> 같은 날: "튜토리얼과 초반게임은 익숙한 고구려 백제 이런 걸로" · "게임 패키지처럼 정말 이거 해보고 싶다라는 마음이 들게".
> **정할 것은 맨 끝 §5 — 형이 고른다.**

## 0. 무엇인가

자유 판(정복·맹주·철·제사로 이기는 지금의 판)과 따로, **사료에 남은 사건 하나를 한 장(章)으로** 짠 판들의 줄.
장마다 ① 익숙한 주인공 ② 그 사건다운 **특수한 승리 조건** ③ 그 장에만 있는 규칙 하나 ④ 표지 그림·이야기가 있다.
문명의 시나리오처럼 짧고(한 판 15~40계절) 목표가 또렷하다. 장을 이기면 다음 장이 열리고, 휘장과 계승 장수가 따라온다(META).

뿌리는 『삼국사기』·『삼국유사』가 먼저다 (메모리: 한국 중심 고대사). 위서 동이전은 곁들임.

## 2. 엔진에 필요한 것 — 작게 쪼개서

판(Realm)에 `scenario` 하나를 얹는다 — 엔진은 조건을 계절마다 셈하고, 화면은 막대로 보인다 (숫자 대신 감).

```
scenario: {
  id, chapter,
  win:  Goal[]   // 모두 이루면 이김 (그 장의 특수 승리)
  lose: Goal[]   // 하나라도 이루어지면 짐 (기본: 도읍을 잃는다 · 기한을 넘긴다)
  limit?: number // 계절 기한
  rules: string[] // 그 장의 규칙 스위치 (pursuit · selfDrum · mire · tahaeDuel · fewerSwords …)
}
Goal =
  | { kind: 'hold', nodes: string[] }                 // 이 고을들을 쥔다
  | { kind: 'submit', factions: string[], how: 'ally'|'tribute'|'either' } // 이 나라들이 따른다
  | { kind: 'fell', hero: string }                     // 이 장수를 쓰러뜨린다 (사로잡음·죽음·저격)
  | { kind: 'trade', partners: number }                // 철을 판 나라 수
  | { kind: 'wed', hero: string }                      // 이 사람과 혼인
  | { kind: 'event', id: string }                      // 그 장의 사건을 이룬다 (활쏘기 겨루기 승리 · 북 찢기 …)
  | { kind: 'survive', seasons: number }
```

- 셈은 `season.checkOutcome` 곁에 `scenarioOutcome(r)` 하나 — 결정론(A1) 그대로, 굴림은 rng.
- 규칙 스위치는 이미 있는 셈에 끼운다: 추격군(AI 한 무리를 계절마다 우리 군대 쪽으로) · 스스로 우는 북(기습 들킴 1) · 수렁(봄·여름 그 길의 말 무리 사기 깎임) · 칼을 덜 뽑음(싸우면 그 나라들의 마음 −) · 탈해 겨루기(사건 카드).
- 활쏘기 겨루기·대소 저격은 **밤 판(저격)** 으로 — 이미 공작 「자객」이 밤 판을 연다. 장의 사건이 같은 문을 쓴다.

## 3. 화면

- 첫 화면에 「캠페인 — 삼국의 새벽」 칸: 장 카드(표지 그림 · 제목 · 때 · 한 줄) 가로 줄. 깬 장은 휘장, 잠긴 장은 앞 장 이름.
- 판 위 오른쪽 위에 **이 장의 목표** 띠: 목표마다 막대(예: 「송양의 마음 ████░░」 · 「행인국 도읍 ✓」 · 「기한 9계절 남음」).
- 장이 열릴 때 서막(세 장) — 사료 한 줄을 그대로 옮긴다(짧게, 쉬운 말로).
- 장을 이기면 끝 화면에 그 장의 그림과 "사서는 이렇게 적었다" 한 줄 · 다음 장 열림.

## 4. 짓는 차례

1. **틀** — `scenario` 꼴 · `Goal` 셈 · 목표 띠 · 장 고르기 칸 · 2장(형제의 강)을 첫 장으로 옮겨 붙이기 (조건: 미추홀 도읍 hold)
2. **1장 주몽** — 땅(혼강·압록 윗줄기 조각) · 나라 넷(고구려·비류국·행인국·북옥저 + 동부여 추격) · 송양 항복(submit) · 활쏘기 겨루기(event, 밤 판)
3. 3장 혁거세 (칼을 덜 뽑는 장 — 외교 위주라 지금 시스템으로 거의 된다)
4. 4·5·6장 — 규칙 스위치 하나씩
5. 7·8장

장마다 표지 그림 한 장(제미나이 · 16:9) · 주인공 명치판 · 시뮬로 "평범하게 두면 깨지나 / 너무 쉽나" 를 잰다 (BALANCE).

## 5. 형이 정할 것

- **Q1 장 고르기** — 위 여덟 가운데 넣을 것과 뺄 것 (지어낸 이야기가 섞인 7장 삼성혈 · 시대가 늦은 8장 나무 사자 포함 여부)
- **Q2 첫 장** — 배우는 판(형제의 강)을 캠페인 2장으로 묶고, 그다음을 1장 주몽으로 (권함) — 아니면 따로
- **Q3 자유 판과의 관계** — 캠페인을 깨야 자유 판이 열리나, 둘 다 처음부터 열려 있나 (권함: 자유 판은 지금처럼 따로 열린다)
