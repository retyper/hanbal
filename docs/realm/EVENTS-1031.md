# 사건 카드 다시 짜기 — 지금 것 표 · 새 안 (형 10-31)

형: *"너무 매 계절 이벤트 뜨고 이벤트들이 다 더 손실이냐 덜 손실이냐 이벤트라서 너무 피로해. 이득 이벤트를 더 많이 설계해야 할 거고
그게 합리적이면서 본 거 또 보는 듯한 걸로 지루하지 않아야 함. 이놈의 장수들은 맨날 싸우기만 하냐. 이벤트에 창의성이 부족함."*

| (2장) 엄리대수 다리 · 비류국 북 | | | | | 그 장만 |

**보이는 것**
- 나쁜 카드 다섯 가운데 넷이 「덜 잃기」 — 어느 쪽을 골라도 잃는다. 형이 피곤하다는 바로 그 결.
- 장수 이야기는 「다툼」 넷과 「연정」 하나뿐 — 장수끼리 할 수 있는 일이 싸움밖에 없다.
- 「이득 고르기」(좋은 것 둘 가운데 하나)는 셋(풍년·해무리·고래)뿐 — 이게 가장 재미있는 결인데 가장 적다.
- 카드가 판의 지도·고을·특산과 거의 안 이어진다 → 어디서 일어났는지 지도에서 안 보인다 (메모리 rules-visible-on-map).

## 2. 새 카드의 규칙

1. **좋은 것 둘 가운데 하나를 고르게** — 「잃을 것 둘 가운데 덜 아픈 것」을 줄인다. 나쁜 카드는 셋에 하나 꼴로만.
2. **장수가 싸움 말고 하는 일** — 가르치고 · 뽐내고 · 만들고 · 그리워하고 · 내기하고 · 노래한다. 이름과 성격(cast)이 말에 나온다.
3. **달력에 박힌 날** — 한 턴 = 한 달이 되면 그해 그달에 꼭 오는 잔치가 생긴다 (기다리는 재미 · 예측되는 기쁨). 사료의 제천 행사를 쓴다.
4. **이어지는 카드** — 이번 고름이 몇 달 뒤 다른 카드를 부른다 ("한 계절만 더").
5. **지도에 보이게** — 그 일이 일어난 고을에 표·연기·깃발이 선다.
6. **같은 카드는 한 해에 한 번** · 판에서 본 적 없는 카드를 먼저.

## 4. 빈도 (한 턴 = 한 달이 되면)

- 달력 잔치(1~5)는 그달에 꼭 — 한 해 너덧 번.
- 나머지 카드는 **세 달에 한 장 꼴** (지금은 계절마다 55%). 같은 달에 잔치가 있으면 다른 카드는 쉬어 간다.
- 나쁜 카드(가뭄·메뚜기·돌림병·바다 도적·다툼)는 모든 카드의 셋에 하나를 넘지 않게. 다툼 넷은 하나로 묶는다.
