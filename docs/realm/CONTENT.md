> 규칙은 SYSTEMS, 이 문서는 **그 규칙에 들어갈 알맹이**다. 데이터 파일(`src/realm/data/`)의 초안이 된다.
> 모든 항목은 **한 문장으로 무엇을 하는지** 말할 수 있어야 한다. 말할 수 없으면 빼거나 쪼갠다.
> `[사료]` 는 WORLD.md 의 근거를, `[상상]` 은 근거 없이 지어낸 것을 뜻한다 (WORLD §5 규칙 1).

## 2. 사건 (첫 판 30장 · 예)

| 갈래 | 사건 | 선택 A | 선택 B |
|---|---|---|---|
| 하늘 | 가뭄 | 소도에 빈다 (곡식 −, 점복 굴림) | 보를 쌓는다 (일손 −, 다음 해 가뭄 −) |
| 하늘 | 장마가 길다 | 나루를 지킨다 (군대 묶임) | 내버려 둔다 (나루 건너편 고을 행군 막힘) |
| 하늘 | 풍년 | 크게 제천 (민심 ++) | 창고에 쌓는다 (곡식 ++) |
| 하늘 | 메뚜기 | 불을 지른다 (밭 −, 메뚜기 끝) | 기다린다 (수확 −30~60%) |
| 하늘 | 해무리 | 출정을 미룬다 | "길한 징조"라 부르며 나간다 (사기 +, 소문 표식) |
| 사람 | 두 장수가 다툰다 | 한쪽 편을 든다 (한쪽 충성 +, 다른 쪽 −) | 둘 다 내보낸다 (따로 떨어진 고을로) |
| 사람 | 혼인 청 — 이웃 나라 | 받는다 (화친, 장수 하나 그쪽 친족) | 거절한다 (관계 −) |
| 사람 | "?"가 열렸다 | (정보 사건 — 선택 없음) | |
| 사람 | 늙은 장수가 물러나길 청한다 | 보낸다 (그의 제자가 들어온다) | 붙잡는다 (충성 −, 능력 −1/해) |
| 사람 | 군장의 아이가 태어났다 | (후계 후보 — PLAY §6) | |
| 바깥 | 군현의 사신 | 공물을 바친다 (위세품 +, 철 −) | 돌려보낸다 (긴장도 +) |
| 바깥 | 왜의 배 | 철을 판다 (철 −, 곡식·위세품 +) | 배를 붙잡는다 (배 +, 왜 관계 −) |
| 바깥 | 북에서 온 망명자 | 받는다 (기병 장수 · 북방 관계 −) | 돌려보낸다 |
| 바깥 | 해적 | 맞선다 (포구 전투) | 몸값을 낸다 |
| 소도 | 도망자가 소도로 들어갔다 | 내버려 둔다 (천군 관계 +) | 끌어낸다 (모든 나라 민심 −10) |
| 소도 | 천군의 말 | 따른다 (다음 계절 명령 하나가 정해진다 · 민심 +) | 무시한다 |

> 사건의 수는 30장에서 시작해 **장수에게 붙는 사건**(특성·관계에서 생기는 것)을 늘려 간다.
> 정해진 사건보다 사람에게서 나오는 사건이 많아질수록 림월드처럼 이야기가 저절로 생긴다.
