# 신궁: 칠십팔국 — 대개편 설계 묶음

> 2026-10-17 시작. 형: *"활쏘기는 게임내 서브게임으로 적장 암살을 통한 적군 약화에 쓸거야.
> 기본적으로 옛날 한반도무대로 지형과 전략을 고려한 전쟁, 적장사살포획, 국가운영 이런느낌."*
> 그리고: *"바로 뭔가 만들지 말고 완벽을 기한 설계부터 잡아."*

**이 묶음이 끝나기 전에는 코드를 쓰지 않는다.** 설계가 형의 확인을 받으면 `BUILD.md` 6장의
첫 단면부터 만든다.

| 문서 | 무엇 | 읽는 순서 |
|---|---|---|
| [VISION.md](VISION.md) | **무엇을 만드는가** — 정체성, 제약, 기둥, 루프, 슬롯머신, 진행과 엔드게임 | 1 |
| [WORLD.md](WORLD.md) | **어디인가** — 원삼국 시대(1~3세기), 사료, 세력, 지리, 고증 규칙 | 2 |
| [SYSTEMS.md](SYSTEMS.md) | **어떻게 돌아가는가** — 지도·정보·전투·장수·암살판·고을·외교·사건·기술, 공식과 초안 수치 | 3 |
| [BUILD.md](BUILD.md) | **어떻게 짓는가** — 아키텍처, 기존 코드 재사용, 검증, 마일스톤, 위험, 열린 질문 | 4 |

## 한 줄 정의

**78개 소국이 철을 두고 다투던 원삼국의 한반도에서, 활 잘 쏘는 작은 나라의 군장이 되어
지형과 정보로 싸우고, 적장을 쏘아 맞히고, 사로잡은 장수들로 나라를 굴린다.**
한 계절이 한 턴이고, 한 턴은 30초다.

## 기존 문서와의 관계

- `docs/GDD.md` 의 활 물리·빨간 바 계약은 **암살판 안에서 그대로 산다.** 바뀌는 것은 그 바깥이다.
- `docs/ARCHITECTURE.md` A1~A8 은 새 전략 층(`src/realm/`)에도 **똑같이** 걸린다.
- GDD 1장의 C1~C6 은 VISION.md 1장의 **W1~W7** 로 다시 쓴다. 바뀐 것과 이유는 거기 적는다.
- GDD 9장(광고·결제·출석·리더보드·가챠 금지)은 **한 줄도 안 바뀐다.**
