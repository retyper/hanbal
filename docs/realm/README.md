## 한 줄 정의

**78개 소국이 철을 두고 다투던 원삼국의 한반도에서, 활 잘 쏘는 작은 나라의 군장이 되어
지형과 정보로 싸우고, 적장을 쏘아 맞히고, 사로잡은 장수들로 나라를 굴린다.**
한 계절이 한 턴이다. **제1순위는 재미와 중독성** (VISION §1).

## 용어 — 설계의 말과 화면의 말

| 설계 문서 | 화면 | 왜 |
|---|---|---|
| 군장 | 칭호: 읍차 · 살해 · 번예 · 험측 · 신지 (WORLD §6-1) | "군장"은 요즘 말로 군대 배낭이 먼저 떠오른다 · 칭호는 사료에 있다 |
| 저격 (옛 "암살판") | 저격 | "판"이 스테이지·치세·사냥판으로 세 겹이었다 · 다리를 쏘는 게 핵심인데 "암살"은 죽이는 말 |
| 생포 (옛 "포획") | 생포 · 사로잡다 | 포획은 짐승에 쓰는 말 |
| 도감 (옛 "장수록") | 도감 | 장수록은 長壽(오래 삶)로도 읽힌다 |
| 난세 단계 (옛 "천명 단계") | 난세 | 천명(민심)과 겹치고 "천 명"으로 읽혔다 |
| 점복 | 점괘 | 뜻이 바로 온다 |
| 희귀도 흑·백·청·황·적 | 보통 · 좋음 · 드묾 · 귀함 · 전설 (색만 오방색) | 화면에서 "적"은 적군이다 |
| 정보의 계약 | (화면에 내지 않는다) | 설계 내부의 약속 |
| 혼 · 소문 | 혼 · 소문 | 그대로 선다 |
