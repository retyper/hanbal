# 각성 영상 제작과 검수

Veo는 각성 초상용이다. 전투 스프라이트를 Veo로 만들지 않는다. 신규 제작은 20~30대 여장수 1차를 먼저 진행한다. 좋은 구도 기준은 말갈기·소서노 v2·쇠비 1차의 머리~골반을 채우는 세로 화면이다. 완벽한 루프보다 얼굴·손·도구와 자연스러운 움직임을 우선한다.

반영 네 영상은 원본 비교·시점 표본·인접 프레임 변화 후보를 시각 검수했다. 모든 프레임의 손가락을 수동 판독했거나 소리/립싱크를 직접 확인했다는 뜻은 아니다. 소리 직접 검증은 현재 미완이며 원본 오디오는 보존한다. 사용자 불합격 결과는 자동 재생성하거나 반영하지 않는다.

## 재개 절차

1. 제작 큐와 원장, 실제 Gemini 진행/완료 요청부터 대조한다. 실제 UI에 표시된 해제 시각만 cooldown에 기록한다.
2. 원본의 얼굴·손 파지가 머리~골반 9:16 안에 들어가는지 먼저 확인한다. 무기 끝이나 바깥 배경 일부는 잘릴 수 있지만 파지 손을 통째로 잃는 구도를 강행하지 않는다.
3. 새 대화의 Veo 비율은 16:9로 초기화될 수 있다. 세로 9:16 선택과 첨부 원본을 제출 직전에 확인한다. 정사각 인셋·흐린 띠를 넣지 않는다.
4. 확정 문안을 한도 재개 전에 준비한다. 대표 동작 하나와 호흡·옷의 후행을 연결한다. 과도한 동시 동작이나 서로 충돌하는 고정 조건을 줄인다.
5. 첫 편을 생성해 검수한 뒤 나머지 서로 다른 인물을 신속히 이어서 처리한다. 준비·등록 때문에 제출을 지연하지 않고 생성 대기 시간을 활용한다.
6. 10초를 하나의 연속 촬영으로 지시한다. 중간의 자세·표정 초기화, 숨은 편집, 순간 크기 변화, 억지 루프 복귀를 금지한다. 문안만으로 보장되지 않으므로 실제 결과도 확인한다.
7. `tools/veo/continuity.py`로 인접 프레임의 절대 변화와 주변 대비 급변 후보를 찾고 원본 전후 프레임을 본다. 첫/끝 루프 경계는 별도다. 수치만으로 자동 PASS를 내지 않는다.

CLI·해시 고정·중복 차단·잠금 복구는 [도구 설명](../../tools/veo/README.md)을 따른다. 인물별 원본·문안·제출 URL·파일·검수와 예약 시각은 제작 채팅의 `outputs/veo-production-queue.json`, `veo-production-state.json`, `veo-queue-runbook.md`가 관리한다.
