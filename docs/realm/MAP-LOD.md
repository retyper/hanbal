# 지도 간소화 단계 (MAP-LOD)

형 11-04: "이 정도 축소되면 더 간소화되어야 하는데, 화면에 오브젝트 개수를 세어서 확대 축소에 따라 간소화를 진행하는 보더라인을 경계 그어 놔야 할 것 같고 각 수준에 따른 축소 규칙들 다 깔끔하게."

## 1. 남들은 어떻게 하나

| 사례 | 하는 것 | 우리가 가져온 것 |
|---|---|---|
| 지도 그리기(Mapbox) | 글씨마다 중요도(sort key) · 겹치면 덜 중요한 것이 숨는다 · 카메라가 움직여도 자리가 흔들리지 않게 | 이름표 중요도(지킬 곳 → 도읍 → 우리 고을 → 남의 고을 → 빈땅) · `declutter.ts` |
| Sins of a Solar Empire · ICBM | 멀리 가면 지도가 "종이 지도"가 되고 유닛은 기호(아이콘)로 · 단계마다 이름이 있다(전술 · 지역 · 세력) | 단계 셋: 가까이 · 중간 · 멀리 |
| Planetary Annihilation 제안 | 겹친 유닛은 기호 하나 + 모서리에 수 · 기호도 중요도 순으로 겹친다 | (다음) 겹친 군대 묶기 |
| Travian Kingdoms | 확대 단계마다 보이는 층과 거르개가 다르다 | 단계마다 보이는 것을 표로 못 박는다(아래) |
| CK3 · EU4 | 멀리 보면 고을 이름 대신 나라 이름을 땅 위에 크게 | 「멀리」의 나라 이름 (FOCUS G · 이미 있었다) |

출처: [Mapbox 글씨 자리 잡기](https://docs.mapbox.com/help/dive-deeper/optimize-map-label-placement/) · [Mapbox 충돌 처리](https://github.com/mapbox/mapbox-gl-native/wiki/Collision-Detection) · [Ashes 줌 논의(Sins 종이 지도)](https://forums.sorcererking.com/470288) · [Planetary Annihilation 전략 아이콘](https://forums.planetaryannihilation.com/posts/719229) · [Travian Kingdoms 지도](https://support.kingdoms.com/en/support/solutions/articles/7000071734-map-and-markers)

**모두의 공통점** — (1) 단계는 몇 개로 딱 끊는다(연속으로 흐리게 하지 않는다) · (2) 단계마다 보이는 것의 목록이 정해져 있다 · (3) 같은 단계 안에서는 중요도로 겹침을 푼다 · (4) 고른 것·위험한 것은 어느 단계에서도 보인다.

## 2. 경계선 — 배율이 아니라 화면이 얼마나 빽빽한가

옛 규칙은 배율만 봤다. 그래서 고을 서른넷을 가진 큰 나라는 「가까이」 배율인데 화면에 고을이 스물다섯 개 넘게 들어와 다 그려졌다(형의 우산국 화면).

이제 `zoom.ts tierOf` 가 둘을 보고 **더 간소한 쪽**을 고른다.

- **빽빽함** = √(보이는 칸 넓이 ÷ 그 안에 보이는 고을 수) — 고을 하나가 차지하는 화면 한 변(px)
  - `mapLodNearPx` (120px) 이상 → 가까이
  - `mapLodMidPx` (72px) 이상 → 중간
  - 그 아래 → 멀리
- **배율** — 빽빽한 판(영남·남녘·온 땅)은 옛 경계(`mapZoomMidAt` · `mapZoomNearAt`) 그대로. 드문 판(배우는 판·변한)은 배율로는 「멀리」만 가른다 — 처음 여는 배율에서 걷는 군사가 그대로 보이게
- 경계에서 깜빡이지 않게 지금 단계 쪽으로 `mapLodHyst`(8%) 끈다
- 다시 재는 때: 배율이 바뀔 때 · 다 밀고 손을 뗐을 때(보이는 고을이 바뀐다)

## 3. 단계마다 보이는 것

| | 가까이 | 중간 | 멀리 |
|---|---|---|---|
| 고을 그림 | ○ | ○ | ○ |
| 고을 이름 | 모두 (겹치면 남의 고을부터 숨김) | 도읍 · 우리 고을 · 우리와 맞닿은 고을 (겹치면 우리 여느 고을도 숨김) | 우리 도읍 · 지킬 곳만 + 나라 이름 |
| 이름표 곁 특산 칸 · 옛 이름 · 깃발 칩 | ○ | ✕ | ✕ |
| 길 기호(표지) · 고을 둘레 무늬 | ○ | ✕ | ✕ |
| 군대 | 장수 얼굴 + 걷는 군사 + 수 + 사기 줄 | 얼굴 + 수 + 사기 줄 | 얼굴 + 수 |
| 「명령?」 말풍선 | ○ | ✕ | ✕ |
| 「개척단 필요」 · 군사 이동 필요 칩 | ○ | 고른 고을만 | 고른 고을만 |
| 움직이는 길 점선 | 흐른다 | 멈춘다 | 멈춘다 |

**어느 단계에서도 보이는 것** (`.lkeep`): 고른 고을 · 위협받는 우리 고을 · 칠 채비가 모인 고을 · 고른 군대와 그 갈 곳 칩 · 다가오는 적 화살.

규칙은 `mapview.ts MAP_CSS` 의 `data-zl` 줄들에 있다 — 단계가 바뀌면 속성 하나만 바뀌고 CSS 가 다 한다.
