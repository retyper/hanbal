# 쫀득한 손맛 — 몰입과 누르는 맛 (2026-10-23 밤 공부)

> 형 (2026-10-23): *"UX 가 참 중요한데 우리 같은 게임에서 어떻게 몰입감, 사용하는 쫀득감 이런 걸 줄 수 있는지 공식 공부해 와 봐"*
> 판정(src/realm)은 건드리지 않는다 — 손맛은 꾸밈에서만 낸다 (A1). 시간 값은 params 로.

## 1. 원칙

1. **누르면 0.1초 안에 무언가 바뀐다.** 0.1초 = "내가 했다", 1초 = 생각이 이어짐, 10초 = 딴 데로. — https://www.nngroup.com/videos/3-response-time-limits-interaction-design/ · Swink "Game Feel" https://en.wikipedia.org/wiki/Game_feel
2. **작게 누르고 크게 돌려받는다 (juice).** 규칙은 그대로, 늘였다 줄이기·부드러운 움직임·소리만 더해 살아난다. — Jonasson & Purho "Juice it or lose it" https://www.gamedeveloper.com/design/video-is-your-game-juicy-enough-
3. **큰 순간엔 잠깐 멈춘다 (hit stop).** 맞는 순간 몇 프레임 세우고, 맞은 쪽을 더 흔들고, 흔들림은 줄여 간다. — 사쿠라이 https://sourcegaming.info/2015/11/11/thoughts-on-hitstop-sakurais-famitsu-column-vol-490-1/
4. **흔들림은 세기 단계를 정해 두고 아껴 쓴다.** — Nijman "The art of screenshake" https://www.youtube.com/watch?v=AJdEqssNZ-U
5. **준비 동작 → 동작 → 여운, 그리고 짧게.** 들어오는 것 ~225ms · 나가는 것 ~195ms · 400ms 넘으면 느리다 · 들어올 땐 감속 곡선. — https://m1.material.io/motion/duration-easing.html
6. **결과는 차례로 쌓는다.** 한 번에 보여 주지 말고 하나씩 튀며 숫자가 굴러 오른다 (발라트로). — https://gmtk.substack.com/p/balatros-cursed-design-problem
7. **적의 다음 수를 그림으로 미리 보인다 (telegraph).** 인투 더 브리치 · 슬레이 더 스파이어의 의도 그림. — https://www.pcgamer.com/into-the-breach-preview
8. **손에 잡히는 물건처럼.** 카드를 섞고 끄는 것을 만지는 물건처럼 (하스스톤). — https://toucharcade.com/2014/11/07/hearthstone-a-conversation-with-devs-at-blizzcon
9. **그림·소리·떨림이 같은 순간에 같은 뜻.** 진동 무늬 하나에 뜻 하나 · 남발 금지 · 끌 수 있게. — https://developer.apple.com/design/human-interface-guidelines/playing-haptics
10. **쓰기 쉬움 + 빠져듦.** 표시와 반응·또렷함·한결같음·실수 막기와 되돌리기 / 하고 싶은 마음·감정·흐름. — Hodent https://celiahodent.com/understanding-the-success-of-fortnite-ux/

## 2. 우리 게임에 대입 (✅ 있음 · ⬜ 없음)

있는 것: 누르는 소리 일곱 갈래 · 깃발마다 소리·연출 · 판 펼칠 때 카드 차례로 · 싸움 흔들림·번쩍 · 계절 띠 · 이김 큰 글자·불티·진동 · 점령 깃발·금빛 고리 · 위협 붉은 맥동 · 길 금빛 흐름 · 싸움 누르면 빨라짐 · 움직임 줄이기 설정 · 명령마다 취소.

## 3. 하지 말 것

1. 조작을 막는 긴 연출 — 다 누르면 건너뛰거나 빨라진다. 지도 위 움직임은 400ms 를 넘지 않는다.
2. 흔들림·번쩍 남발 — 한 화면 한 번, 정한 단계대로.
3. 진동의 뜻 섞기·남발 — 좋은 일과 나쁜 일에 같은 무늬 금지, 단추마다 울리지 않는다, 끌 수 있게.
4. 숫자 폭죽 — 떠오르는 수는 사람 수·곡식처럼 원래 보이는 것만. 확률은 말과 색으로 (숫자 대신 감).
5. 일정한 속도로 들어오기 — 들어올 땐 감속, 나갈 땐 가속.
6. 보여 준 것과 다른 결과 — 몰래 확률을 바꾸지 않는다 (결정론 · 정보의 계약).
