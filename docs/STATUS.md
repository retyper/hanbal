## 3. ★ 다음에 할 일 (우선순위)

### 1순위 — 사람 눈으로 확인 (아직 아무도 안 봤다)
아래는 **숫자로 답할 수 없어서** 형이 직접 봐야 하는 것들이다:
- [ ] **소리가 실제로 나는가.** 헤드리스에는 `AudioContext`가 없어 한 번도 못 들어봤다
- [ ] **양궁 자세가 자연스러운가** (`docs/FORM.md` 규격은 좌표로 8항목 통과했지만 눈으로는 미확인)
- [ ] **폭발 화살이 "손해 본 것 같은지"** — 화살은 아끼는데 점수가 기본보다 낮다
- [ ] **드래프트가 귀찮은가** — 판 넘김에 2클릭(넘기기 1 + 카드 1)
- [ ] 화살 개수 표시·빨간 바·점수 팝의 가독성

### 2순위 — 알려진 문제
- [ ] **★★★이 44%** (목표 5~30%). 앞 40판이 쉬워서 무손실이 기본값이 됐다.
      별을 조이는 게 아니라 난이도 정책과 같이 봐야 한다
