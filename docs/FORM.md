# 사법(射法) — 스틱맨 자세 규격

> 사용자 피드백: **"캐릭터가 몸뚱이가 굽어져 있는 게 좀 어정쩡하잖아. 제대로 된 양궁 자세로 해줘야지."**

이 문서는 `src/render/stickman.ts`가 그려야 할 자세를 관절 단위로 규정한다.
"멋있게"가 아니라 **실제 양궁 사법대로** 그린다. 활을 아는 사람이 봤을 때 틀린 데가 없어야 한다.

---

## 0. 가장 중요한 한 가지 — T자

올림픽 리커브 사법의 핵심은 **T-form**이다.

```
        ○  머리 (표적 쪽으로 돌아감, 턱이 앞어깨 위)
        │
   ╲    │    ╱
    ╲   │   ╱          ← 두 팔이 수평으로 뻗어 T의 가로획
 팔꿈치 ┼ 어깨 ────────── 활손          ← 이 선이 하나의 직선
        │
        │              ← 척추가 T의 세로획: **완전히 수직**
        │
       ╱ ╲             ← 다리는 곧게, 어깨너비
```

**몸통은 절대 굽지 않는다. 절대 뒤로 젖혀지지 않는다.**
지금 스틱맨이 어정쩡해 보이는 이유가 이것이다. 조준 방향이 바뀌어도
**상체(어깨-팔-화살)만 어깨를 축으로 회전하고, 척추는 수직을 유지한다.**

---

## 1. 골격 비율 (전체 키 H 기준)

발바닥을 y=0, 머리 꼭대기를 y=H로 둔다.

| 부위 | 위치 / 길이 |
|---|---|
| 머리 중심 | y = 0.925H, 반지름 0.065H |
| 턱 (앵커 높이) | y = 0.86H |
| 어깨 (양팔 회전축) | y = 0.82H |
| 골반 | y = 0.50H |
| 무릎 | y = 0.26H |
| 발 | y = 0 |
| 앞발 / 뒷발 | 골반 x 기준 ±0.11H |
| 활팔 (어깨→활손) | 0.36H |
| 윗팔 (어깨→당김팔꿈치) | 0.21H |
| 아랫팔 (팔꿈치→앵커손) | 0.19H |
| 활 전체 길이 | 0.62H |

## 2. 관절 규칙

### 2-1. 하체 — 언제나 고정
- 두 다리는 **곧게**. 무릎을 굽히지 않는다.
- 앞발이 표적 쪽으로 조금 앞, 뒷발이 조금 뒤. 체중은 가운데.
- 조준 각도가 바뀌어도 **하체는 전혀 움직이지 않는다.**

### 2-2. 척추 — 언제나 수직
- 골반(0.50H) → 어깨(0.82H)는 **정확히 수직선**.
- 위로 조준하든 아래로 조준하든 굽히지 않는다.
- 예외는 붕괴 경고(`warn`)뿐. 3-3 참조.

### 2-3. 머리
- 표적 쪽을 향해 돌아가 있다. 턱이 앞어깨 위에 온다.
- 머리는 조준각을 따라 **살짝만** 기운다 (조준각의 25% 정도). 통째로 돌리지 마라.

### 2-4. 활팔 (앞팔) — 곧게 뻗는다
- 어깨에서 **조준 방향으로 곧게** 뻗는다. 팔꿈치를 굽히지 않는다.
- **어깨가 으쓱 올라가면 안 된다.** 초보의 대표적 실수이고, 보기에도 어정쩡하다.
  어깨선은 항상 0.82H에 고정.

### 2-5. 당김팔 (뒷팔) — 여기가 사법의 핵심
세 가지를 지켜야 양궁으로 보인다:

1. **앵커(anchor)**: 시위를 잡은 손이 **턱 아래(0.86H)** 에 붙는다.
   허공에 떠 있으면 안 된다. 만작에서 손이 얼굴에 닿아 있어야 한다.
2. **화살 = 직선**: 활손 → 앵커손 → 아랫팔 → 팔꿈치가 **하나의 직선** 위에 놓인다.
   화살은 이 선과 정확히 겹친다.
3. **팔꿈치가 높다**: 당김팔꿈치는 화살 선상이거나 **살짝 위**.
   아래로 처지면 이른바 '닭날개'로, 초보 자세의 대표 증상이다.

당김팔꿈치 위치 = 앵커에서 조준 반대 방향으로 0.30H, 위로 0.02H.

### 2-6. 활과 시위
- 활은 활손 위치에서 조준 방향에 **수직**으로 선다. 위아래 대칭.
- 시위는 활 양 끝 → 앵커손. 만작일수록 깊게 당겨진다.
- 활의 휨은 `draw`에 비례. 만작에서 가장 깊게 휜다.
- 활과 시위는 몸통보다 **얇게** 그린다. 굵기 위계: 몸통 > 팔다리 > 활 > 시위 > 화살.

## 3. 상태별 변형 — 자세로 정보를 전달한다

기본은 항상 **정자세**다. 아래는 그 위에 얹는 편차이고, 각각 **다른 것**을 말해야 한다.

### 3-1. `draw` 0 → 1 (당기는 중)
- 앵커손이 활손 근처에서 출발해 턱으로 온다.
- 당김팔꿈치가 따라 올라간다. 만작에서 규정 위치.
- 척추·하체는 미동도 없다.

### 3-2. `maxDraw` < 1 (근력 부족 — 성장 전)
**"아직 힘이 모자라다"를 자세로 보여주는 자리.** 하지만 **고장 나 보이면 안 된다.**
- 앵커손이 턱까지 못 온다. 턱 앞 (1 - maxDraw) × 0.18H 지점에서 멈춘다.
- 당김팔꿈치가 규정 높이보다 (1 - maxDraw) × 0.06H 낮다 (닭날개의 기미).
- **척추는 여전히 수직.** 몸을 굽혀서 표현하지 마라 — 그게 지금 어정쩡한 이유다.
- `maxDraw`가 1.0에 닿으면 앵커손이 턱에 딱 붙고 팔꿈치가 제 높이로 올라온다.
  **이 순간의 변화가 눈에 확 띄어야 한다.** 성장의 시각적 보상이다.

### 3-3. `strain` 0 → 1 (빨간 바를 넘음)
- 0이면 **완전히 고요한 정자세.** 흔들림 0. "지금 쏘면 맞는다"가 몸으로 읽혀야 한다.
- 커지면 떨림이 시작된다. 떨림은 어깨를 축으로 한 각 오프셋이라 활 끝에서 가장 크게 나타난다.
- 여기서는 **자세를 무너뜨리지 마라.** strain은 "떨린다"만 말한다.

### 3-4. `warn` 0 → 1 (붕괴 임박)
strain과 **역할이 겹치면 안 된다.** warn은 "곧 놓쳐버린다"를 말한다.
- 앵커손이 앞으로 밀려나기 시작한다 (creeping — 실제 붕괴 직전 증상).
- 당김팔꿈치가 처진다.
- 활팔 어깨가 으쓱 올라간다 (버티려고 힘을 잘못 쓰는 것).
- **여기서만** 척추가 살짝 굽는다. warn × 0.04H 정도. 이게 유일한 예외다.

구현 후 아래를 눈으로 확인한다. 하나라도 아니면 다시.

- [ ] 위/아래 어느 쪽을 조준해도 척추가 수직인가
- [ ] 만작에서 시위 잡은 손이 턱에 닿아 있는가
- [ ] 활손 → 앵커 → 팔꿈치가 한 직선인가

- [ ] 활팔 어깨가 으쓱 올라가 있지 않은가
- [ ] 무릎이 굽어 있지 않은가
- [ ] STR 0과 STR 14의 자세 차이가 한눈에 보이는가
- [ ] strain 0에서 완전히 정지해 있는가
