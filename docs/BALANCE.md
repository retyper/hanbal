# 밸런스 기록

`npm run balance` 출력만이 근거다. 감으로 적지 않는다.
값을 바꿀 때마다 **날짜 / 무엇을 / 왜 / 측정값**을 표에 추가한다.

## 목표 수치

| 지표 | 목표 |
|---|---|
| 챕터별 average 봇 첫시도 클리어율 | 55~75% |
| 새 메커닉 챕터 클리어율 하락 | ≤ 25%p |
| novice~expert 클리어율 격차 | 30~50%p |
| 25분 공부 후 플레이 가능 판 수 | ≥ 3판 |
| 스탯 1포인트 후반 효과 | ≥ 초반의 20% |
