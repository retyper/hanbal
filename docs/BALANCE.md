# 밸런스 기록

`npm run balance` 출력만이 근거다. 감으로 적지 않는다.
값을 바꿀 때마다 **날짜 / 무엇을 / 왜 / 측정값**을 표에 추가한다.

## 목표 수치

| 지표 | 목표 |
|---|---|
| 챕터별 average 봇 첫시도 클리어율 | 55~75% |
| 새 메커닉 챕터 클리어율 하락 | ≤ 25%p |
| novice~expert 클리어율 격차 | 30~50%p |
| 25분 공부 후 플레이 가능 판 수 | ≥ 3판 |
| 스탯 1포인트 후반 효과 | ≥ 초반의 20% |

## 변경 이력

| 날짜 | 변경 | 이유 | 측정 결과 |
|---|---|---|---|
| 2026-08-23 | 초기 세팅 | — | 측정 전 |
| 2026-08-23 | `core/rng.ts` gaussian의 Box-Muller 캐시 제거 | 캐시가 `state()`에 안 들어가 같은 시드로 되감아도 산포가 달라졌다 (A1 위반). 난수열이 통째로 바뀌므로 아래 수치는 이 커밋 기준으로 다시 잰 것이다 | 난이도 순서 불변 |
| 2026-08-23 | `bow.releaseScatter` 0.011 → 0.0035, `tremor.baseAmp` 0.0042 → 0.016 | 산포가 떨림의 6.9배라 완벽한 릴리즈가 각오차를 1.0%밖에 못 줄였다 = 실력이 통계적으로 존재하지 않음 (feel-lens blocker). 총 오차 예산을 난수에서 읽을 수 있는 떨림으로 이동 | 떨림 RMS 0.0016 → 0.00603 rad, 산포 σ 0.011 → 0.0035 (비 1.72x), 완벽 릴리즈 개선폭 1.0% → 49.8%, 총 σ 0.01112 → 0.00697. **1-9 클리어율 격차 11.0%p → 22.0%p**, 1-9 expert 한발명중 83.9% → 97.1% / novice 38.5% → 34.4%. average 클리어율은 전 판 100%로 변화 없음(이전에도 포화) |

> 남은 숙제 (balance-lens): average 클리어율이 챕터 1 전 판에서 100%로 포화해 목표(55~75%)를 25%p 초과한다.
> 릴리즈 산포를 줄여 총 오차가 63%가 됐으므로 **난이도는 과녁 반경·거리로 되돌린다. 난수로 되돌리지 않는다** —
> 난수를 키우면 위 blocker가 그대로 재발한다. 격차 목표(30~50%p)에도 1-9만 22%p로 아직 못 미친다.
