# 플레이테스트

코드가 컴파일된다는 것과 게임이 재밌다는 것은 다른 문제다. 눈으로 본다.

## 절차

### 1. 정적 검증부터
```bash
npm run typecheck
npm test
```
여기서 깨지면 브라우저를 열지 않는다. 먼저 고친다.

### 2. dev 서버
```bash
npm run dev
```
백그라운드로 띄운다(`run_in_background: true`). 출력에서 실제 포트를 읽는다 — 5173이 점유돼 있으면 다른 포트로 뜬다.

### 3. 브라우저
`claude-in-chrome` 스킬을 먼저 호출한 뒤 브라우저 도구를 쓴다.
- `tabs_context_mcp` 로 현재 탭 확인 → `tabs_create_mcp` 로 새 탭에 dev URL 열기
- `computer` 로 스크린샷
- `read_console_messages` 로 에러 확인 (pattern 인자로 필터링)

### 4. 실제로 쏴본다
스크린샷만 찍고 끝내지 않는다. `computer` 도구로:
- 캔버스 위에서 마우스 다운 → 유지 → 이동 → 업 (한 발 쏘기)
- 당기는 중간 프레임을 캡처해 **떨림이 눈에 보이는지** 확인
- 붕괴(스태미나 0)까지 홀드해서 경고가 보이는지 확인

### 5. 보고
형에게 보고할 때:
- 스크린샷 1~2장 (당김 중 / 명중 순간)
- 콘솔 에러 있으면 그대로
- **손맛에 대한 소견** — 무엇이 어색한지. 없으면 없다고.

## 주의
- 브라우저 alert/confirm을 띄우는 조작은 하지 않는다. 확장이 멈춘다.
- 끝나면 dev 서버를 정리한다 (`TaskStop`).
- 형이 이미 dev 서버를 띄워뒀을 수 있다. 포트 충돌 시 새로 띄우지 말고 기존 것을 쓴다.
